# F001 — Memory

Воспоминания — это папка, объединяющая всё медиа с одного мероприятия: встречи, поездки, чего угодно.

- Создаётся как папка/контейнер под конкретное мероприятие.
- Организатор задаёт название воспоминания и дату (или интервал) мероприятия при его создании.
- Дата мероприятия используется F002 для автоподбора медиа из галереи участника.
- В воспоминание приглашаются конкретные люди — те, кто был на мероприятии.
- Приглашать можно только пользователей этого приложения — у приглашённого должен быть аккаунт.
- Приглашают либо поиском пользователя внутри приложения, либо ссылкой-приглашением.
- Главный экран приложения — список всех воспоминаний пользователя (где он организатор или участник).

## Права доступа

Каждому приглашённому выдаётся один из двух уровней доступа к материалам воспоминания.

- Просмотр — только смотреть материалы.
- Добавление — смотреть, добавлять материалы и приглашать в воспоминание новых людей.
- Каждый может удалить только свой собственный загруженный материал.
- Организатор (создатель воспоминания) может удалить любой материал, кем бы он ни был загружен.
- Удалить воспоминание целиком (все материалы и ролики, у всех участников) в MVP нельзя.
- Организатор может исключить участника из воспоминания; участник может выйти из него сам.
- При исключении или выходе весь загруженный участником материал удаляется вместе с ним.
