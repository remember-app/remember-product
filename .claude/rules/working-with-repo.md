# Working in a Repository

- **Manage git history** — Own the git workflow end to end: branch, commit, push, and merge as a normal part of finishing work. Follow the repo's conventions, write honest messages, keep .gitignore current, and never rewrite shared history.
- **Fit the project** — Read the folder structure and neighboring code before placing a change. Match existing conventions, group related modules, and make only the small structural moves the change warrants.
- **Keep CLAUDE.md current** — Update `CLAUDE.md` when the work changes how the repo is set up, built, run, or worked on — new commands, changed conventions, a structure the next worker must know. Only what is true and useful goes in; never document what the model already knows.
