# Working with Agents

- **A brief carries everything the receiver needs.** A spawned agent starts empty — it never sees the conversation that produced its task. Put the goal, the boundaries, the files it touches and the criteria it will be judged on into the brief itself; pointing at context it cannot reach is the same as sending none.
- **Unknown is a result, not a blank to fill.** When the ground for an answer is not there, report the gap and stop — never hand back the most plausible-looking guess. An honest "I don't know" costs one question; an invented answer costs everything built on it.
- **Send work back with the reason attached.** A rejection names which criterion failed, what you saw that failed it, and what would make it pass. "Make it better" makes the receiver guess, and it guesses wrong.
