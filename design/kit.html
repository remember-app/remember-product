Remember

The photo lab. A memory is a contact sheet — every frame everybody shot, laid on one sheet, before the edit picks the keepers. The interface is silver and black and stays quiet, so the photographs are the only colour on the screen. One ink runs through it: the amber edge print of film stock, and it only ever carries numbers.

One superfamily, two widths. Archivo — a signage grotesque, not a UI default — carries everything a person reads. Archivo Narrow carries the edge print, the way a real film edge is marked in condensed type. Line length stays under 60 characters at phone width.

Edge print

The bespoke device, and the only tracked-out type in the product. It carries data — frame numbers, counts, dates, sizes, durations. Never a label above a heading, never a category name, never decoration.

frame 041 214 frames 812 mb 3–8 may 1:04

Numerals are tabular, so a count that ticks upward during an upload does not shift the layout underneath it.

Space, rule, radius

Spacing steps 4 · 8 · 12 · 16 · 20 · 24 · 32 · 48. Radius is not one value: frames are 2 (a frame is a frame), controls are 10, panels 14, pills full. Separation is a 1px hairline in Edge plus a step in value — there are no shadows and no gradients anywhere, which also means nothing here needs a native blur or gradient dependency.

Building this in the app

Nothing here needs a native dependency: no gradients, no blur, no shadows. Every layout is flexbox with gap, which React Native supports. Two font packages to add — @expo-google-fonts/archivo and @expo-google-fonts/archivo-narrow. The app is dark-only, so userInterfaceStyle should be pinned to dark, and the splash and Android icon background move off the Expo template blue to #0B0E0D.
