# Remember — дизайн «Афиша»

Это готовый макет приложения: 46 экранов в виде обычного HTML. Открывается
в браузере, ничего не собирается, ничего не устанавливается.

- `index.html` — контактный лист: все экраны сразу, сгруппированы по разделам.
  Начинать смотреть отсюда.
- `screens/<Name>.html` — один экран, 390×844 (кроме листов-компонентов и
  `System.html` — 760×940).
- `img/f01…f12.jpg` — **заглушки**. Это сгенерированные размытые пятна, а не
  фотографии. В коде на их месте — реальные кадры из воспоминания.

Макет — источник правды по виду, отступам, цветам и тексту. Он не источник
правды по данным: цифры («12 файлов», «4 из 7») подставлены руками.

---

## 1. Направление

«Афиша» — тёмный зал, светлый кадр. Приложение про то, как чужие телефоны
складываются в один ролик, поэтому интерфейс ведёт себя как афиша к фильму:
крупный заголовок, много воздуха, фотография — главный элемент, а не
декорация. Ярко, но не пёстро: два акцентных цвета на всё приложение.

Правила, из которых собран весь макет:

1. **Акцент — ровно одно главное действие на экране.** Синий `accent` не
   используется для декора, иконок, текста или второстепенных кнопок.
2. **`spark` (кислотный жёлтый) — это организатор, «готово» и прогресс.**
   Больше ни для чего.
3. **Затемнения только поверх фотографий** и только градиентом сверху/снизу,
   никогда сплошной плашкой.
4. **Никакого фейкового статус-бара.** Верхние 52px в макете просто пустые —
   там системный статус-бар устройства.
5. **Нет скроллов там, где их не должно быть.** У каждой доски
   `overflow: hidden` на `html`, `body` и корневом блоке. Где контент реально
   длиннее экрана (галерея, список воспоминаний) — вертикальный скролл
   контента; горизонтальных скроллов нет нигде, кроме ленты кадров в
   просмотрщике.
6. **Цель нажатия ≥44px** всегда, даже если иконка 22px.

| токен | значение | что это |

| `surface` | `#16161F` | карточка, лист, поле ввода |
| `raise` | `#22222E` | приподнятое над карточкой (чип, аватар-заглушка) |
| `line` | `#2C2C3A` | обводка 1px |

### Шрифты

```
Unbounded  600, 700   — заголовки, крупные числа
Onest      400…700    — весь остальной текст
```

Оба с кириллицей. Прошлый набор был на Bricolage Grotesque — у него
кириллицы нет вообще, это была настоящая поломка, а не вкусовщина.

### Шкала

| роль | размер / интерлиньяж | шрифт |
|---|---|---|

Всё, где есть цифры (счётчики, даты, таймкоды, размеры) — обязательно

### Радиусы и ритм

`card 26` · `sheet 22 (верхние углы листа 28)` · `frame 14` · `pill 999`.
Шаг отступов 4. Поля экрана 16. Высота кнопки 56. Высота поля ввода 52.

## 3. Экраны

Порядок — как в `index.html`.

### Главный экран и создание
- `Main` — список воспоминаний, тёмная тема. Заголовок Remember по центру,
  под ним обещание продукта. Карточка = обложка + название + даты + строка
  участников.
- `HomeDay` — тот же экран в светлой теме.
- `Create` — создание воспоминания: название, даты, обложка.
- `System` — плитка стиля: токены, шрифты, кнопки, чипы, иконки.

### Ядро воспоминания
- `MemoryFrames` — галерея кадров, сетка 3 в ряд. Снизу: фильтры слева,
  «Добавить ещё» по центру, сортировка справа.
- `FramesByPeople` — та же галерея, сгруппированная по тому, кто принёс.
- `MemoryFilms` — ролики воспоминания.
- `MemoryPeople` — участники, статусы загрузки, кнопка «Пригласить».
- `Upload` — выбор кадров из галереи телефона.

### Компоненты воспоминания (листы, открываются поверх)
- `SheetFilter` — фильтр: по людям (с аватарками-инициалами), по типу,
  по дате.
- `SheetSort` — сортировка.
- `SheetInvite` — позвать людей: ссылка, контакты, ник.

### Аккаунт и контакты
- `Account` — профиль, разделы, среди них «Контакты»; внизу крупная красная
  кнопка выхода без подписи.
- `Contacts` — список знакомых ников.

### Онбординг
- `Login` — три равные кнопки: Apple, Google, Почта.
- `LoginEmail` — ввод почты.
- `LoginCode` — шесть ячеек кода.
- `Consent` — согласие на обработку.
- `Username` — «Придумайте ник».

Шапка на всех пяти одинаковая и не двигается. После регистрации человек
попадает сразу на главный экран, а если пришёл по приглашению — сразу
в воспоминание. Нового воспоминания в онбординге нет.

### Ролик: заказ по шагам (4 шага)
- `MontageSelect` — шаг 1: что берём.
- `SheetRejected` — лист: что не взяли и почему.
- `MontageStory` — шаг 2: про что ролик.
- `MontageMusic` — шаг 3: музыка.
- `MontageBuild` — шаг 4: сборка и подтверждение.
- `MontageProgress` — сборка идёт.

### Просмотр медиа
- `Viewer` — фото во весь экран, плавающая панель сверху, плотная лента
  кадров и панель действий снизу. Худ в духе системной галереи.
- `ViewerVideo` — то же для видео: шкала, таймкод.
- `SheetFrame` — лист сведений о кадре.

### Пусто и необратимое
- `HomeEmpty`, `FramesEmpty`, `FilmsEmpty` — пустые состояния.
- `SheetConfirmDelete`, `SheetConfirmMember` — подтверждения.

### Ожидание и отказы
- `HomeLoading` — скелетоны.
- `HomeOffline` — баннер «Нет соединения» сверху, экран работает.
- `HomeOnline` — «Соединение установлено», баннер уходит сам.
- `UploadAccess` — доступ к галерее не дан.
- `UploadLimited` — доступ дан частично (iOS).
- `UploadQueue` — очередь отправки.
- `SheetTooLittle` — кадров слишком мало для ролика.

### Приглашение и края
- `InviteJoining` — вступаю по ссылке.
- `InviteDead` — ссылка отозвана.
- `SheetAskAll` — «Это всё?» после отправки.
- `FramesPicking` — режим выбора в галерее.
- `ContactsEmpty`, `UploadEmpty` — пустые состояния.

## 4. Тексты

Весь текст, который уже есть в `projects/mobile/src/strings.ts`, взят оттуда
дословно. Словарь продукта не меняется: **воспоминание**, **кадры**,
**участники**, **ролик**.

Новое обещание на главном экране:

> После события кадры расходятся по десяти телефонам.
> Здесь они сходятся обратно — и становятся роликом.

## 5. Что придётся поменять в коде

Макет местами опережает текущую реализацию. Это осознанно, вот список:

1. **Статус вклада в списке воспоминаний.** Карточка на `Main` показывает,
   кто уже принёс кадры. Сейчас `GET /memories` этого не отдаёт — нужно
   поле со сводкой участников (кто загрузил / кто нет) прямо в листинге,
   иначе главный экран потребует N запросов.
2. **Вход по коду вместо magic-link.** `LoginEmail` → `LoginCode`: шесть
   цифр. Текущая схема со ссылкой в письме под этот макет не подходит.
3. **`profile.title` → «Аккаунт»** (было «Профиль»), и «Контакты» переезжают
   внутрь этого раздела — отдельной иконки в шапке главного экрана больше
   нет.
4. **Заказ ролика — мастер из 4 шагов** по `backlog/docs/doc-03` и `doc-11`.
   Старый лист с тремя переключателями больше не существует.
5. **Экран согласия** по `backlog/docs/doc-04` и `backlog/decisions/decision-9`.
6. **Разбор «героев» (узнанные люди и животные) в макете намеренно
   отсутствует** — это ответственность монтажёра, отдельного шага в
   приложении нет.
