## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Единственный источник правды — design/kit.html, секции 2-14 (компоненты), плюс раздел «Голос» (пол доступности, строки 783-800). Брать токены из TASK-35 (theme.ts), не заводить свои цвета/отступы. Файлы — по вкусу коду (папка компонентов), но имена компонентов/пропсов пусть перекликаются с именами классов кита, чтобы экраны было легко сверять с китом. Лист подтверждения — react-native Modal снизу с анимацией rise, не сторонняя библиотека bottom-sheet. Компоненты пока нигде не подключены к экранам — это будущая задача каждого экрана.
