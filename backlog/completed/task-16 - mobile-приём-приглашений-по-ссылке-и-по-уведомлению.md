## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Замкнуть круг приглашения со стороны приглашённого: телефон регистрируется на уведомления, переход по ссылке-приглашению добавляет человека в воспоминание, а нажатие на уведомление открывает приложение сразу на экране загрузки этого воспоминания. Сам экран загрузки пока заглушка.
