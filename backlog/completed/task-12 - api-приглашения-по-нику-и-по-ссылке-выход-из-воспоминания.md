## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
В воспоминание зовут людей: либо находят по нику, либо дают ссылку-приглашение, которую можно отозвать. Приглашённому уходит уведомление с призывом загрузить фото. Организатор может исключить участника, участник может выйти сам.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Приглашать по нику может организатор или участник с правом добавления; смотрящий — нет
- [x] #2 Повторное приглашение уже добавленного ничего не ломает
- [x] #3 У воспоминания одна живая ссылка-приглашение; после отзыва старая перестаёт работать, выдаётся новая
- [x] #4 Переход по живой ссылке добавляет человека с её уровнем доступа; отозванная и неизвестная дают понятный отказ
- [x] #5 Организатор исключает других, любой участник выходит сам; организатор выйти не может
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [x] #1 Уведомление уходит после того, как участник уже записан, и его неудача не откатывает приглашение
<!-- DOD:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Уведомления через Expo Push, один раз, без повторов. Без настроек пуша полезная нагрузка пишется в лог, а не падает. В месте исключения участника оставлен именованный крючок, куда следующая команда подвесит удаление его медиа. Живая проверка на устройстве не проводилась — ключей и устройства не было.
