## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Если вход человека перестал действовать (вышел с другого телефона, кончился срок), экран монтажа пишет «Связь пропала, ждём» и без конца спрашивает сервер, хотя дело не в связи.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Ответ «не вошли» на любой запрос приложения приводит к одному понятному поведению во всём приложении (выход на экран входа), а не к бесконечным опросам
- [ ] #2 Есть тест на записанном ответе; журнал монтажа больше не опрашивает при таком ответе
<!-- AC:END -->

## Definition of Done

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Найдено при исправлении журнала m-27 (кодер и ревьюер приложения). Клиент api при 401 просто бросает ошибку; токен при 401 удаляется только на старте приложения (src/auth.tsx ~стр. 59). Как это переживают галерея и лента роликов, опрашивающие по таймеру, — не проверяли. Чинить в одном месте (клиент api → выход из сеанса), не в хуке журнала. Сначала проверить, что решение по выходу из сеанса уже нигде не принято.
