## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Для проверки дублей экран загрузки читает весь список кадров воспоминания при каждом монтировании, и сразу после отправки очередь монтируется и тянет его второй раз — каждый ответ несёт подписанные ссылки на все кадры. Вдобавок снимок списка не обновляется за визит: только что отправленный и снова выбранный файл не попадёт в сверку (в той же сессии очередь и так не даст отправить тот же ассет дважды). Долг: не читать лишний раз и обновлять снимок перед отправкой. Требует решения по api (например, «только свои» или метаданные без ссылок), поэтому отдельно.
<!-- SECTION:DESCRIPTION:END -->
