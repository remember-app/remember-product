## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
При правке m-42 кнопка паузы в видео уходит вместе с интерфейсом. Но у экранного диктора нет способа сам интерфейс скрыть или вернуть: сцена с видео намеренно не размечена как доступный элемент, чтобы не перекрыть кнопку паузы. Для фото такой путь есть. Долг доступности: дать диктору действие скрыть/вернуть интерфейс над видео, не отнимая у него кнопку паузы.
<!-- SECTION:DESCRIPTION:END -->
