## Description

Из отчёта TASK-400: 1) в React Native кэш замеров текста (TextMeasureCache.h) не учитывает потолок роста: всё, что меняет потолок у уже нарисованного текста (fitCell в днях календаря и на ползунке), рисуется мельче в коробке прежней высоты; в ките уменьшение текста делается через сам размер шрифта, а не через потолок — описано в README; остальные места проверить; 2) при смене ступени системного шрифта без перезапуска (AX-XXXL → L через simctl) плитки и строки этапов на готовом ролике остаются высокими с мелким текстом, перезапуск лечит; 3) каждый Text кита теперь подписан на размеры окна и перерисовывается при смене шрифта или поворота — цена стража, оценить на слабых устройствах; 4) слабые места рецептов стенда: плитки на SE при L на 0.5 пт ниже окна рецепта, SheetLiveFile на крупном шрифте тапает запись за краем, системный вопрос о фото на AX-XXXL не отвечается — перенести исправления в states-fixed.mjs.
