# Media Upload

## What it does
Приглашённый участник кладёт в воспоминание свои фото и видео прямо с телефона — так весь материал
с мероприятия от всех, кто там был, стекается в одно место, без уговоров и общего чата. Чтобы не
листать всю галерею и не отмечать кадры по одному, приложение по дате мероприятия само находит
снятое в это окно и предлагает выборку разом: участник убирает лишнее и только потом отправляет.
Загруженное показывается общей галереей воспоминания, и догрузить можно в любой момент — в том
числе после того, как ролик уже смонтирован.

## What it doesn't
- Грузить можно только с телефона: веб- и десктоп-клиента нет.
- Без аккаунта и без приглашения в воспоминание загрузить нельзя (decision-01).
- Без явного согласия участника на доступ к медиатеке не забирается ничего.
- Уведомлений о новых загрузках нет — post-MVP.
- Видео отдаётся прогрессивным превью 720p; адаптивного стриминга нет.
- Забрать оригиналы себе — не здесь, это Gallery Download.

## Components
- [ ] Выбор медиа из галереи телефона с запросом доступа к медиатеке
- [ ] Кнопка «Выбрать все за эту дату» по окну мероприятия из Memory
- [ ] Отсев лишнего из выборки перед отправкой
- [ ] Отправка файлов в хранилище с докачкой при обрыве
- [ ] Превью для фото и постер с лёгкой версией для видео
- [ ] Галерея воспоминания
- [ ] Участник удаляет свой материал, организатор — любой
- [ ] Материал участника уходит вместе с ним при выходе или исключении

## Dependencies
- [x] Memory — есть куда грузить и есть окно мероприятия для автоподбора
- [x] Accounts
- [ ] Файловое хранилище с подписанными ссылками на загрузку
- [ ] Фоновый обработчик с настоящими обработчиками медиа — сейчас только скелет очереди

## Done when
- [ ] All components complete
- [ ] Участник кладёт фото и видео в воспоминание с телефона и видит их в галерее
- [ ] «Выбрать все за эту дату» набирает снятое в окно мероприятия, лишнее убирается до отправки
- [ ] Оборванная загрузка докачивается, а не начинается заново
- [ ] Догрузить можно и после того, как ролик уже смонтирован
- [ ] Материал вышедшего или исключённого участника исчезает из воспоминания
