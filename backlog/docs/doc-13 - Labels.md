# Labels

## What it does
Участник раскладывает кадры воспоминания по лейблам — своим коробкам с названием и цветом.
Лейбл либо общий (его видят все участники воспоминания), либо личный (видит только хозяин).
Кадры складываются в лейбл пачкой: отметил несколько в режиме выбора и положил. Один кадр может
лежать в нескольких лейблах сразу, кадр при этом не копируется и из воспоминания никуда не
девается.

## What it doesn't
- Лейбл не даёт и не отнимает прав: положить чужой кадр в свой лейбл можно, но это не делает его
  твоим и никому ничего не открывает.
- Личный лейбл не виден никому, кроме хозяина, — ни его название, ни состав.
- Лейбл не переносит кадры между воспоминаниями: он живёт внутри одного.
- Удаление лейбла не удаляет кадры.
- Как смотреть содержимое лейбла, макет пока не рисует — предложение из макета: раздел «Лейблы»
  в фильтрах.

## Components
- [ ] Лейбл: название, цвет, общий или личный
- [ ] Связь кадра с лейблом: один кадр в нескольких лейблах
- [ ] Положить выбранные кадры в лейбл пачкой из режима выбора
- [ ] Новый лейбл прямо из этого листа: название, цвет, общий или личный
- [ ] Убрать кадр из лейбла, переименовать и удалить лейбл
- [ ] Личный лейбл не виден другим участникам — закреплено тестом
- [ ] Отбор кадров по лейблу в фильтрах галереи

## Dependencies
- [x] Memory — лейблы живут внутри воспоминания
- [x] Media Upload — раскладывать нечего, пока кадров нет
- [ ] Режим выбора кадров по новому макету — из него лейблы и ставятся

## Done when
- [ ] All components complete
- [ ] Участник кладёт несколько кадров в лейбл одним действием и видит их там
- [ ] Общий лейбл виден всем участникам воспоминания, личный — только хозяину
- [ ] Кадр лежит в нескольких лейблах и не дублируется в галерее
- [ ] Удаление лейбла не трогает сами кадры
