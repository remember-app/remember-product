# Accounts

## What it does
Человек заводит аккаунт в приложении — через Apple, через Google или по ссылке на email. Под этим
аккаунтом его зовут в воспоминания и находят другие участники: у него есть уникальный ник, который
он придумывает при первом входе и может сменить в любой момент. Наличие аккаунта — условие, чтобы
быть приглашённым куда бы то ни было.

## What it doesn't
- Пароля нет ни в каком виде.
- Идентификации по номеру телефона и матчинга контактов нет.
- Аккаунты не сливаются: ни между способами входа, ни по совпадающему адресу почты.
- Удаления аккаунта в MVP нет.
- Истории ников не ведём — освобождённый ник сразу свободен для других.

## Components
- [x] Вход по ссылке на email
- [x] Уникальный ник: занять при первом входе, сменить в любой момент
- [x] Поиск другого пользователя по нику
- [x] Сессии: список своих, отзыв любой, выход
- [ ] Вход через Apple — написан, но без ключей провайдера выключен
- [ ] Вход через Google — написан, но без ключей провайдера выключен
- [ ] Доставка ссылки настоящим письмом — сейчас ссылка печатается в лог сервера
- [ ] Пользовательское соглашение при регистрации — отдельной строкой называет распознавание лиц и
      животных на загруженных фото и видео (decision-9); принимается при регистрации, даже на пилоте
      для друзей

## Dependencies
- [x] None

## Done when
- [ ] All components complete
- [x] Ник уникален без учёта регистра, а освобождённый сразу занимается заново
- [x] Другого пользователя находят по нику — на этом стоят приглашения
- [x] Человек видит свои сессии и может закрыть любую из них
- [ ] Человек входит любым из трёх способов на настоящем устройстве
- [ ] Ссылка на вход приходит на почту, а не в лог сервера
- [ ] Зарегистрироваться, не приняв соглашение, нельзя; распознавание лиц и животных в нём названо
      отдельной строкой
