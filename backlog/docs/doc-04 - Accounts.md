# Accounts

Пользователь создаёт аккаунт в приложении. Под аккаунтом человека приглашают в воспоминания и
находят другие участники.

- Наличие аккаунта — условие, чтобы быть приглашённым в воспоминание.
- Вход — через Apple, через Google или по ссылке на email.
- У пользователя есть ник; ник уникальный, и его можно сменить в любой момент.
- Других пользователей находят по нику — чтобы пригласить в воспоминание.
