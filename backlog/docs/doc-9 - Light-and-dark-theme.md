# Light and dark theme

## What it does
У приложения две темы — тёмная и светлая. Тёмная уже есть: это «Тёмная комната» из кита, где
интерфейс уходит в тень и светятся только кадры. Светлой ещё нет — её надо нарисовать в ките той
же рукой и по тем же правилам, а потом перенести в приложение. Тема берётся от телефона, человек
может поставить свою руками.

## What it doesn't
- Тем ровно две. Никаких пользовательских палитр и акцентов на выбор.
- Светлая тема не переизобретает раскладку: те же компоненты, тот же ритм, другой свет.
- Медиа не перекрашивается ни в одной теме — кадр остаётся единственным ярким пятном.
- Отдельного экрана настроек не заводим: переключатель живёт там же, где выбор языка.

## Components
- [ ] Светлая палитра нарисована в ките — все токены цвета, свет и границы, тем же правилом
- [ ] Токены в приложении читаются из темы, а не из одного жёстко заданного набора
- [ ] Тема берётся от телефона, человек может переключить её и выбор запоминается
- [ ] Оба набора держат пол доступности из кита: контраст текста не ниже 4.5:1
- [ ] Все экраны выглядят собранно в обеих темах, включая пустые состояния и ошибки

## Dependencies
- [ ] Светлая палитра в ките — рисует дизайнер, до этого перенос в приложение невозможен
- [x] Вид приложения уже собран по киту (веха m-7)

## Done when
- [ ] All components complete
- [ ] Телефон в светлом режиме — приложение светлое, в тёмном — тёмное
- [ ] Переключение темы руками меняет всё приложение без перезапуска и переживает перезапуск
- [ ] Ни на одном экране в светлой теме не остаётся тёмных пятен и нечитаемого текста
- [ ] Контраст проверен в обеих темах
