# Contacts

## What it does
Человек складывает к себе ники тех, кого зовёт в воспоминания, и в следующий раз приглашает их
из своего списка, не вспоминая и не набирая ник заново. Организатор одного мероприятия почти
всегда собирает те же лица и на следующем — список контактов убирает повторный ввод и главную
причину не позвать кого-то: «лень искать».

## What it doesn't
- Это не друзья: связь односторонняя, согласия второй стороны не спрашивают и уведомления ей
  не шлют.
- Список ничего не открывает: попадание в чужие контакты не даёт ни доступа к воспоминаниям,
  ни видимости чего-либо.
- Нет запросов, подтверждений, взаимности и статуса «в сети».
- Список не подтягивается из телефонной книги и не ищет людей по номеру или почте.
- Нет групп и списков рассылки — только плоский список ников.

## Components
- [ ] Сохранить человека в контакты по нику
- [ ] Список контактов у человека, с поиском по нему
- [ ] Приглашение в воспоминание выбором из контактов
- [ ] Удалить человека из контактов
- [ ] Тот, кого позвали не из контактов, предлагается к сохранению

## Dependencies
- [x] Accounts — ник и поиск людей по нику
- [x] Memory — приглашение в воспоминание

## Done when
- [ ] All components complete
- [ ] Человек сохраняет ник и в следующем воспоминании зовёт его в два касания, ничего не вводя
- [ ] Удалённый контакт исчезает из списка и из выбора при приглашении
- [ ] Список виден только своему хозяину
