# Language

## What it does
Приложение говорит с человеком на его языке — русском или английском. Сейчас интерфейс английский,
кит и письмо со ссылкой входа русские, а даты выводятся русской системной локалью прямо посреди
английских подписей. Продукт выбирает язык сам по языку телефона, а человек может поставить другой
руками. Вместе с языком меняется всё, что человек читает: подписи, ошибки, пустые состояния,
письмо со ссылкой входа, тексты уведомлений, формат дат.

## What it doesn't
- Языков ровно два: русский и английский. Третий не заводим.
- Перевод не машинный: оба языка пишутся руками, английский не калька с русского.
- Пользовательские тексты — названия воспоминаний, ники — не переводятся.
- Отдельного экрана настроек под это не заводим: выбор языка живёт там, где уже есть профиль.

## Components
- [ ] Все читаемые человеком строки приложения вынесены из экранов в одно место
- [ ] Русский и английский набор строк, оба написаны руками
- [ ] Язык берётся от телефона, человек может переключить его в профиле и выбор запоминается
- [ ] Даты и числа выводятся по выбранному языку, а не по системной локали
- [ ] Письмо со ссылкой входа и тексты уведомлений уходят на языке получателя
- [ ] Словарь продукта из кита соблюдён в обоих языках: воспоминание, кадры, участники, ролик
