# Memory

## What it does
Воспоминание — это папка под одно мероприятие: встречу, поездку, что угодно. Организатор создаёт
её, задаёт название и дату (или интервал) события и зовёт туда тех, кто там был — поиском по нику
или ссылкой-приглашением. Приглашённому приходит уведомление с призывом загрузить свои фото и
видео, и оно открывает приложение сразу на нужном воспоминании. Главный экран приложения — список
всех воспоминаний человека, где он организатор или участник.

## What it doesn't
- Не пускает внутрь без аккаунта: приглашать можно только пользователей приложения. Гостевой вклад
  по ссылке без установки приложения отклонён (decision-01).
- Не хранит и не показывает сам материал — это Media Upload.
- Удалить воспоминание целиком в MVP нельзя.
- Передать роль организатора нельзя.
- Организатор не может выйти из своего воспоминания.

## Components
- [x] Создание воспоминания: название и окно мероприятия (начало, необязательный конец)
- [x] Список воспоминаний человека на главном экране
- [x] Участники и три уровня доступа: организатор, добавление, просмотр
- [x] Приглашение поиском по нику
- [x] Приглашение ссылкой, с отзывом старой ссылки
- [x] Уведомление приглашённому с переходом на экран загрузки этого воспоминания
- [x] Исключение участника организатором и выход по своей воле
- [ ] Материал вышедшего или исключённого участника удаляется вместе с ним

## Dependencies
- [x] Accounts — приглашают только пользователей приложения и находят их по нику

## Done when
- [ ] All components complete
- [x] Организатор создаёт воспоминание с названием и окном мероприятия и видит его в списке
- [x] Приглашённый по нику и по ссылке попадает внутрь с тем уровнем доступа, который ему выдали
- [x] Отозванная ссылка перестаёт работать, а выданная взамен работает
- [x] Не участник не может отличить чужое воспоминание от несуществующего
- [x] После выхода или исключения материала участника в воспоминании не остаётся
