# Frame Comments

## What it does
Участник может оставить комментарий к кадру — своему или чужому — прямо в воспоминании: подписать,
что здесь происходит, пошутить, назвать людей. Комментарии видят все участники воспоминания, и их
же читает режиссёр монтажа: для него это контекст, которого нет в самом изображении — что за
событие, кто в кадре, почему этот момент важен.

## What it doesn't
- Комментарий не меняет сам кадр и не влияет на то, кому он виден.
- Это не переписка о воспоминании в целом — комментарий всегда привязан к конкретному кадру.
- Уведомлений о новом комментарии не обещаем, пока человек не скажет иначе.

## Components
- [ ] Комментарий к кадру: написать, увидеть, удалить свой
- [ ] Комментарии видны всем участникам воспоминания
- [ ] Комментарии кадра доходят до режиссёра как контекст при сборке ролика
- [ ] Комментарий уходит вместе с кадром, когда кадр удаляют

## Dependencies
- [x] Memory — комментировать нечего вне воспоминания
- [x] Media Upload — комментарий живёт у кадра
- [x] AI Video Montage — ради режиссёра это и делается

## Done when
- [ ] All components complete
- [ ] Участник оставляет комментарий к кадру, и его видят остальные участники
- [ ] Режиссёр в своём плане опирается на то, что написано в комментариях — видно в журнале сборки
- [ ] Удаление кадра уносит его комментарии
