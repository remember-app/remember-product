# Gallery Download

## What it does
Приглашённый участник забирает фото и видео из общей галереи воспоминания себе на телефон — как
отдельный файл, так и всю галерею разом. Файлы отдаются в том же качестве, в котором их загрузили,
без пережатия. Ролик — то, что расшаривают наружу; оригиналы — то, что забирают себе.

## What it doesn't
- Ничего не пережимает и не переименовывает — отдаёт ровно загруженное.
- Скачивание смонтированного ролика — не здесь, это AI Video Montage.
- Скачать может только приглашённый в это воспоминание, посторонним ссылка не отдаётся.
- Выборочной пачки (отметить пять кадров и забрать их) нет: либо один файл, либо вся галерея.

## Components
- [ ] Скачать один файл в исходном качестве
- [ ] Скачать всю галерею воспоминания разом
- [ ] Скачивание доступно всем участникам, включая уровень «просмотр»

## Dependencies
- [x] Memory
- [ ] Media Upload — скачивать нечего, пока ничего не загружено
- [ ] Файловое хранилище с подписанными ссылками на скачивание

## Done when
- [ ] All components complete
- [ ] Участник забирает отдельный файл и получает ровно тот, что был загружен
- [ ] Участник забирает всю галерею воспоминания одним действием
- [ ] Участник с уровнем «просмотр» тоже может скачивать
- [ ] Посторонний по той же ссылке не получает ничего
