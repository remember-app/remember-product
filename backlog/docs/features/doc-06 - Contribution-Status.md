# Contribution Status

Вне MVP. У каждого приглашённого в воспоминание есть статус его вклада. По нему организатор видит,
кто уже скинул материал, кто ещё грузит, а от кого ждать нечего. Статус ведётся внутри
воспоминания, отдельно по каждому участнику.

- Пока участник ничего не загрузил, он в начальном статусе.
- После первой загрузки приложение спрашивает: всё загружено или есть ещё что подгрузить позже — и ставит статус по ответу.
- Участник может сменить свой статус сам — например, отметить, что фотографий у него нет и ждать от него нечего.
- Организатор видит прогресс по всем участникам воспоминания.
- Если у участника начальный или промежуточный статус, ему может прийти уведомление с напоминанием загрузить материал.
