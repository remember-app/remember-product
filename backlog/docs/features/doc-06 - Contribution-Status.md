# Contribution Status

## What it does
У каждого приглашённого внутри воспоминания есть статус его вклада — по нему организатор видит, кто
уже скинул материал, кто ещё грузит, а от кого ждать нечего. Пока участник ничего не загрузил, он в
начальном статусе; после первой загрузки приложение спрашивает, всё ли он загрузил или догрузит
позже, и ставит статус по ответу. Сменить статус можно и самому — например, отметить, что
фотографий нет и ждать нечего.

## What it doesn't
- Статус ведётся внутри одного воспоминания, отдельно по каждому участнику, а не глобально по человеку.
- Автонапоминание загрузить материал участнику в начальном или промежуточном статусе — вне MVP
  (decision-03). Место под него в статусах предусмотрено.
- Статус не режет права: человек с любым статусом грузит и смотрит как обычно.

## Components
- [ ] Начальный статус у каждого приглашённого
- [ ] Вопрос после первой загрузки и статус по ответу
- [ ] Смена статуса участником по своей воле
- [ ] Прогресс по всем участникам у организатора
- [ ] На карточке воспоминания в списке видно, кто уже скинул кадры (макет «Афиша», 2026-09-18)

Уточнено человеком 2026-09-08 по живому устройству: видимые статусы называются «Планирует
загрузить» и «Всё загрузил», а рядом со статусом показывается, сколько фото и видео участник уже
загрузил. Кнопка «мне нечего добавлять» остаётся, но мельче — она распирала строку участника.

## Done when
- [ ] All components complete
- [ ] Организатор видит по каждому участнику: скинул, догрузит позже или ждать нечего
- [ ] После первой загрузки участник отвечает на вопрос и его статус меняется
- [ ] Участник ставит «ждать нечего» сам, ничего не загрузив
