# Кэш медиа на телефоне

## What it does

Фото и видео, которые приложение уже показало, сохраняются на телефоне и читаются оттуда.
Поэтому возврат на экран не показывает серые плитки и не ждёт сети: кадр, обложка или видео
появляются сразу. А то, что уже лежит на телефоне, видно и без интернета.

## What it doesn't

- Не управляет размером кэша и не даёт его удалять — это следующий шаг, отдельной работой.
- Не скачивает заранее то, что человек не открывал: на телефон ложится уже пришедшее.
- Не делает офлайн всё приложение: без сети доступны только уже загруженные кадры и видео;
  списки, действия и заказ ролика требуют сети.
- Не меняет сервер.

## Components

- [ ] Хранилище на телефоне: кадр, его превью и видео ложатся на диск под устойчивым ключом и
      переживают перезапуск приложения.
- [ ] Чтение: галерея, лента и просмотр берут файл с диска, если он там есть, и только иначе —
      из сети.
- [ ] Возврат на экран: сетка карточки и лента не мигают серым — рисуются из сохранённого.
- [ ] Видео играет из локального файла, прогресс идёт ровно.
- [ ] Офлайн: уже загруженные файлы открываются и показываются без сети.

## Dependencies

- [ ] Нет — штатных средств хранения на устройстве хватает.

## Done when

- [ ] Повторный заход на главный экран не показывает пропадающую и вновь грузящуюся сетку.
- [ ] Повторное открытие кадра или видео не делает сетевого запроса за файлом.
- [ ] Уже загруженные файлы видны при выключенной сети.
- [ ] Код соответствует этой спецификации, ревью и автотесты пройдены.
