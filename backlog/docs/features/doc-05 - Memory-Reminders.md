# Memory Reminders

## What it does
Приложение само возвращает человека к его старым воспоминаниям — напоминает, что год назад он был
здесь, и зовёт открыть их снова. Из напоминания человек попадает прямо в то воспоминание.

## What it doesn't
- Не напоминает загрузить материал — это Contribution Status, там свой повод и свой адресат.
- Не заводит своего канала доставки: те же пуш-уведомления, что у приглашений.
- Новых воспоминаний не создаёт и ничего в них не меняет — только возвращает к уже существующим.

## Components
- [ ] Правило, по которому старое воспоминание всплывает: через сколько, как часто, по какому
      поводу. Не выбрано — нужен разговор с организатором, пока сказано только «например, год назад»
- [ ] Уведомление о старом воспоминании
- [ ] Переход из уведомления в само воспоминание

## Dependencies
- [x] Memory — напоминать не о чем, пока воспоминаний нет
- [x] Пуш-уведомления — канал уже стоит на приглашениях

## Done when
- [ ] All components complete
- [ ] Правило всплытия зафиксировано организатором и записано здесь
- [ ] Человек получает напоминание о своём старом воспоминании
- [ ] Из уведомления он попадает в это воспоминание
