# AI Video Montage

## What it does
Когда материал по мероприятию собран, организатор просит смонтировать из него ролик — в любой
момент, не дожидаясь, пока скинут все. Ролик — не склейка по трём переключателям, а то, чем
организатор управляет: описывает текстом историю ролика, сам решает, какие кадры оставить для ролика, а какие
убрать, выбирает музыку. Нейросеть разбирает весь материал — что на каждом кадре и кто на нём:
понимает, что на разных фото и видео один и тот же человек или животное («человек-1 — Лена,
человек-2 — Сергей, животное-1 — Барсик»), — и по этому строит историю ролика. Собирает ролик наш
собственный обработчик. Готовый ролик лежит отдельно от галереи, виден всем приглашённым, а не
только заказавшему, и его можно скачать и расшарить за пределы приложения. Сам ролик и есть
награда за то, что люди скинули медиа — другой награды нет. Это самая важная часть продукта: в
первой версии для пользователей она должна быть рабочей целиком, пусть и не идеальной.

## What it doesn't
- Заказать ролик может только организатор.
- Пожелания задаются под конкретный ролик перед монтажом: история текстом (необязательно), какие
  кадры оставить и какие убрать, музыка, длина и ориентация — горизонтальный или
  вертикальный. Стиль, титры и покадровая правка готового ролика вне MVP.
- Нейросети только разбирают материал и строят план ролика. Сам ролик собирает свой обработчик;
  покупной видео-сервис на весь монтаж не берём (decision-07).
- Материал уходит на разбор облачной нейросети только на платном тарифе, где присланное не идёт на
  обучение чужих моделей.
- Согласие на распознавание лиц и животных дают только зарегистрированные пользователи. Люди на
  кадрах, которые приложением не пользуются, согласия не давали — для пилота на друзьях это
  принято, до публичного запуска это надо решить.
- Права на музыку на пилоте для друзей не учитываем — это не постоянное решение.
- Уже смонтированный ролик не переделывается, даже если участник вышел и в кадре остался он.
- Ролики не смешиваются с галереей исходных фото и видео.
- Во время сборки ничего не отсеивается: брак предлагается убрать только при выборе кадров, решает
  человек. Оставленные кадры равны — ни один не обязан попасть в ролик; режиссёр может не взять
  кадр в историю, это выбор, а не брак (человек, 2026-10-01).
- Кадры, загруженные после заказа, в этот ролик не входят.
- Числа роликов на воспоминание не ограничиваем.

## Components
- [x] Заказ ролика организатором с пожеланиями к длине и треку
- [x] Выбор ориентации ролика при заказе — горизонтальный или вертикальный
- [x] Шаблон ролика: шесть готовых («Для себя», «Быстрый энергичный», «Официальный отчёт»,
      «TikTok · Reels · Shorts», «Для родителей», «Дофаминовая бомба») и «Настроить самому».
      Шаблон — это текст истории, музыка, длина и формат разом (макет, 2026-09-21)
- [x] Автопилот: выбрал шаблон — шаги заказа листаются и заполняются сами, их видно; можно
      остановиться и править руками
- [x] Музыка — список треков любой длины; пусто значит без музыки
- [x] Пожелание к музыке пишется у каждого трека отдельно, а не одно на весь ролик; написанное
      видно подстрочником в строке трека (макет, 2026-09-25)
- [x] Без музыки ролик идёт с живым звуком самих видео, а не немым (макет MontageMusicNone)
- [x] Длина ролика — число секунд, предел: сумма всех видео плюс 2,5 секунды на фото минус
      полсекунды на каждую склейку, но не больше 10 минут — обещанное число достижимо
- [x] Итог перед монтажом: всё выбранное одним экраном, без правки, одна кнопка «Начать монтаж»
- [x] Монтаж в прямом эфире: режиссёр пишет журнал по ходу — этап, файл, мысль, решение
      («беру», «мимо»), куда кадр лёг; журнал идёт на экран вживую
- [x] Журнал хранится вместе с роликом: «как собирался» открывает любой участник и после сборки
- [x] Видно, кто сейчас смотрит монтаж
- [x] Кадр другой формы, чем холст ролика, обрезается по холсту — чёрных полей в ролике нет
      (человек, 2026-09-21)
- [x] Отбор лучших моментов из материала воспоминания
- [x] Сборка и выкладка готового ролика
- [x] Ролики отдельным списком, видны всем участникам
- [x] Уведомление «ролик готов» всем участникам воспоминания
- [x] Скачать ролик и расшарить его наружу
- [x] У ролика есть имя: по умолчанию от шаблона, правится при заказе и потом в сведениях
- [x] Сведения ролика: шаблон, музыка, кадры, файл, кем собран, кто посмотрел, переименовать и удалить
- [x] Повтор упавшей сборки
- [x] Имя ролика: приходит с заказом (название шаблона или своё), без имени — «Ролик на 1:00» по
      длине; организатор переименовывает ролик в любой момент, новое имя видно везде
- [x] Видно, кто из участников уже посмотрел готовый ролик
- [x] Организатор удаляет ролик насовсем — вместе с файлами, он пропадает из списка роликов
- [x] Выбор медиа для ролика: организатор начал создание ролика и отмечает, какие кадры войти
      должны, а какие нет
- [x] Автоматический отсев брака как предложение: при выборе медиа есть автоматический анализ,
      который отмечает за организатора; тот может вернуть отсеянное или убрать то, что алгоритм
      пропустил, — всё до нажатия «смонтировать»
- [x] История ролика текстом — организатор по желанию описывает, о чём ролик
- [x] Понимание материала: нейросеть описывает содержание каждого фото и видео и узнаёт одних и
      тех же людей и животных на разных кадрах
- [x] Режиссёр: нейросеть по описаниям кадров, истории, выбору «включить / исключить» и длине
      строит план ролика — порядок, длительность, акценты; обработчик собирает по нему
- [x] Музыка: библиотека треков, из которой предлагается выбрать, и возможность добавить свою
- [x] Склейки попадают в ритм выбранного трека
- [x] Сервис монтажа собран из отдельных модулей, каждый можно заменить или переставить, не трогая
      остальные
- [x] Все запросы, которые делаем в нейросети, обязательно сохраняются — чтобы их можно было
      анализировать
- [x] Поставщик нейросети меняется настройкой — выбор поставщика на код не влияет
- [x] Речь в видео расшифровывается — что сказано; кто говорит, не определяем (decision-11)
- [x] Описание того, что происходит на фото и видео, обязательно сохраняется и переиспользуется;
      выходы других шагов пайплайна тоже переиспользуются, где это возможно, — второй и следующие
      ролики из тех же медиа выходят дешевле и быстрее

- [ ] Пять этапов сборки по порядку (человек, 2026-10-01): Подготовка — скачать кадры заказа и
      подготовить их к анализу; Анализ — описать каждый ещё не описанный кадр; Режиссура — режиссёр
      рассуждает и строит историю из оставленных кадров; Музыка — склейки в ритм и где громче
      музыка, а где живой звук; Сборка — итоговый монтаж. Отсева внутри сборки нет
- [ ] Оставленные при выборе кадры равны: нет «обязательно включить», режиссёр выбирает из всех
- [ ] Описание кадра — поля плюс свободный текст: что происходит, кто в кадре (метки людей и
      животных, сколько человек), место, время и свет, настроение, план; для видео — движение
      камеры, речь, лучшие моменты с отметками времени; комментарии участников к кадру; и
      подробное описание свободным текстом
- [ ] Режиссёр видит комментарии участников к кадру вместе с его описанием (doc-14)
- [ ] Экран ролика в состояниях: в очереди (место и что заказано), собирается (этап N из 5,
      оставшееся время, «Сейчас», итог пройденных этапов), готов, не получилось (организатору
      «Повторить», участнику — что организатор может запустить заново), нет связи
- [ ] Журнал на каждый этап: ждёт, идёт, готов, остановился; у анализа пометка «описан ранее»,
      у режиссуры части истории, «взял / не взял» с понятной причиной и отрезки видео, у музыки
      доли музыки и живого звука по частям истории, у сборки шаги и примерный процент
      (макеты Film* и Journal*, 2026-10-01)

## Dependencies
- [x] Memory
- [x] Media Upload — монтировать нечего, пока материал не собран
- [x] Решение по подходу к монтажу: свой обработчик против покупного видео-API. Организатор
      постановил 2026-09-02 не начинать до отдельного разговора; 2026-09-05 разрешил делать тем
      решением, что было зафиксировано — своим воркером (decision-07)
- [x] Распознавание лиц и животных разрешено — пересмотр decision-05 (decision-9)
- [x] Согласие на распознавание лиц и животных при регистрации — Accounts
- [ ] Облачная нейросеть: поставщик и потолок трат на пилот — решает человек; платный ключ от него
- [x] Новый дизайн приложения — экраны заказа ролика строятся на нём, а не на старом ките
- [ ] Комментарии к кадрам — Frame Comments (doc-14): без них режиссёру нечего читать

## Done when
- [ ] All components complete
- [x] Организатор заказывает ролик и получает его из материала своего воспоминания
- [x] Всем участникам приходит уведомление, и ролик виден каждому из них
- [x] Ролик скачивается и уходит наружу через обычный «поделиться»
- [x] При нехватке материала заказ отклоняется понятным сообщением, а не молча
- [x] Кадров, убранных при выборе, в ролике нет
- [ ] Во время сборки ни один кадр не отсеивается как брак; кадр, вернутый человеком при выборе,
      участвует наравне с остальными
- [x] До заказа организатор видит, что автоматический анализ отсеял, и может это поправить
- [ ] Ролик, заказанный с историей текстом, собран по этой истории — проверено на записанных ответах, вживую ждёт ключа (decision-10)
- [x] Ролик можно собрать под трек из библиотеки и под свой, и склейки идут в ритм
- [ ] Второй ролик из тех же медиа не описывает заново уже описанные кадры — берёт сохранённое — проверено на записанных ответах, вживую ждёт ключа (decision-10)
- [x] Каждый запрос в нейросеть можно найти и посмотреть после
- [ ] Сборка идёт пятью этапами, у каждого свой журнал; описание кадра — поля, комментарии и свободный текст
