# Media Upload

Приглашённые участники события загружают в него свои фото и видео со своего телефона.

- Решает проблему: без этого людей приходится уговаривать скинуть фото в общий чат, и часть
  материала теряется, потому что общего чата нет или людям лень грузить.
- Результат — единое место, куда стекается весь материал с мероприятия от всех, кто был приглашён.
- Загруженные медиафайлы отображаются как галерея.
- Загрузка не закрывается созданием ролика — фото можно добавлять и после того, как ролик уже сделан.

## Выбор по дате мероприятия

Чтобы участнику не листать всю галерею и не отмечать фото по одному, при загрузке есть
кнопка «Выбрать все за эту дату».

- Приложение по дате мероприятия из m-0 находит в галерее телефона фото и видео, снятые
  в это время, и добавляет их в выборку разом.
- Участник убирает из выборки то, что не хочет публиковать, и только потом загружает.
- Требуется доступ к медиатеке телефона; без подтверждения участника ничего не загружается.
