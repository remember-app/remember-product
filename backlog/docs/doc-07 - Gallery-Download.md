# Gallery Download

Приглашённый участник может сохранить фото и видео из общей галереи воспоминания себе на
телефон, в исходном качестве.

- Скачать можно как отдельный файл, так и всю галерею воспоминания разом.
- Файлы отдаются в исходном качестве — тем же, в котором их загрузил участник, без пережатия.
- Доступно всем приглашённым в воспоминание.
- Скачивание оригиналов не заменяет ролик из m-2: ролик — то, что расшаривают наружу, оригиналы — то, что забирают себе.
