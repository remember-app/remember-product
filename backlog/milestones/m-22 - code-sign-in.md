## Description

Вход по почте шестизначным кодом из письма вместо ссылки и соглашение при регистрации — по
макету «Афиша» (экраны Login, LoginEmail, LoginCode, Consent, Username). Спека — doc-04,
решение о лицах и животных — decision-9.

Что входит:
- сервер выдаёт и проверяет код из шести цифр вместо ссылки; путь для разработки без почты
  остаётся и остаётся закрытым в боевом режиме;
- соглашение принимается при регистрации, без него зарегистрироваться нельзя; распознавание лиц
  и животных названо отдельной строкой; полный текст на пилот — наш черновик, человек его читает;
- Apple и Google на входе скрыты, пока нет ключей;
- пять экранов входа по макету, шапка на них одна и не двигается; после регистрации — главный
  экран, а пришедший по приглашению — сразу в воспоминание.

Серверную часть можно начинать сразу; экраны — после того, как веха Afisha сольёт библиотеку
деталей.

Готов, когда:
- человек входит, введя код из письма, и без принятого соглашения не регистрируется;
- черновик полного текста соглашения показан человеку;
- ревью пройдено, автотесты зелёные.
