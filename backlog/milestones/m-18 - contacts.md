## Description

Новая фича: человек складывает к себе ники тех, кого зовёт, и в следующий раз приглашает их
из своего списка, ничего не набирая. Спека — doc-10 Contacts.

Это не друзья, и это важно: связь односторонняя, согласия не спрашивают, уведомлений не шлют,
попадание в чужой список ничего не открывает и ничего не показывает. Плоский список ников,
видимый только хозяину.

Готов, когда:
- человек сохраняет ник к себе и в следующем воспоминании зовёт его выбором из списка;
- по списку можно искать, из него можно удалить;
- позвавший не из списка получает предложение сохранить;
- чужой список не виден никому, кроме хозяина, и это закреплено тестом;
- вид собран по киту, ревью пройдено, автотесты зелёные.

Вне этого шага: телефонная книга, поиск по номеру и почте, группы, взаимность. Ручное
тестирование — только по прямой отмашке человека.
