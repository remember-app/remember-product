## Description

Приложение переделывается по новому макету «Афиша», который человек нарисовал сам (design/,
начинать с design/README.md). Решение «дизайн заморожен» (decision-8) отменено.

Что входит:
- дизайнер раскладывает макет на повторяющиеся детали и пишет по нему спецификацию, оригиналы
  страниц остаются рядом для сверки;
- из спецификации собирается настоящая библиотека деталей приложения — новые цвета, шрифты с
  кириллицей (Unbounded, Onest), тёмная тема целиком, светлая подстановкой цветов по образцу
  HomeDay;
- все экраны приложения, кроме входа и заказа ролика, переделываются по макету; чистка кода
  экранов идёт первым шагом, уже под макет;
- «Профиль» становится «Аккаунтом», контакты внутри него (doc-04, doc-10);
- на карточке воспоминания видно, кто уже скинул кадры — сервер отдаёт это в списке (doc-06);
- галерея: группировка по тому, кто принёс, фильтры, сортировка, действия с кадром (doc-02);
- плашка «Нет соединения» и её уход, пустые состояния, скелетоны, отказы доступа к медиатеке.

Не входит: экраны входа и согласия — веха Code sign-in; мастер заказа ролика и его листы — веха
Montage director. Им нужна библиотека деталей из этой вехи — её собрать и слить первой.

Готов, когда:
- каждый экран из design/, кроме входа и заказа ролика, в приложении выглядит как в макете;
- библиотека деталей описана историями на каждый вариант и состояние;
- ревью пройдено, автотесты зелёные.

Ручную проверку делает человек сам; агенты — только по его прямому слову.
