## Description

Шаг 6 к MVP: приложение перестаёт выглядеть заглушкой и получает единый вид по киту
«Тёмная комната» — design/kit.html в корне продукта. Кит сделан человеком и является
единственным источником дизайн-правды: цвета, шрифты, ритм, форма, движение, голос.

Кит написан на HTML и CSS. Приложение — React Native, CSS-переменных там нет: токены
переносятся значение в значение с сохранением имён, компоненты собираются средствами RN.

Верстается всё приложение целиком, экран за экраном: вход, ник, список воспоминаний,
создание, экран воспоминания с участниками и приглашениями, приём приглашения, экран
загрузки с контактным листом, галерея, профиль.

Функционал, которого ещё нет, верстается на заглушках — ролик из doc-03 AI Video Montage
(заморожен человеком) и всё, чего не отдаёт API. Заглушка должна быть видимой и честной,
а не выдавать себя за работающее.

Готов, когда:
- токены кита живут в одном месте приложения и оттуда берутся всеми экранами;
- каждый экран приложения выглядит по киту, самодельных цветов и отступов не осталось;
- состояния из кита на месте: пусто, ожидание, ошибка, выключено, необратимое действие
  через лист подтверждения;
- то, чего ещё нет, показано заглушкой по киту и помечено как заглушка в коде;
- миниатюры в сетке выбора рисуются (TASK-27, ждала этого шага);
- пол доступности из кита держится: цель нажатия 44×44, видимый фокус, значок без подписи
  не остаётся, движение выключается системной настройкой;
- пройдено глазами на симуляторе, экран за экраном.

Вне этого шага: новые возможности и изменения в API. Только вид.
