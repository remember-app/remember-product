## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Заказ ролика начинается с выбора из шести шаблонов. Тап по шаблону запускает автопилот: шаги сами листаются и заполняются, видно как, «Стоп» отдаёт руль. «Настроить самому» ведёт по шагам вручную.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Спека: doc-03 («Шаблон ролика: шесть готовых … и «Настроить самому»», «Автопилот: выбрал шаблон — шаги листаются и заполняются сами, их видно; можно остановиться и править руками»), design/spec.md §8 MontageTemplate, §6 «Движение» (абзац «Автопилот по шаблону»), деталь №3 (вид автопилота), №41 (состояния плитки: покой · нажат · выбран автопилотом); макет design/screens/MontageTemplate.html. Сервис: projects/mobile. Ждёт TASK-216, TASK-217, TASK-218: автопилот листает шаги, которые они делают, и приходит на итог.

ЭКРАН «Каким будет ролик» — вход в заказ: шапка мастера без шкалы («Новый ролик», «Отмена»), заголовок, подпись «Выберите шаблон — дальше всё соберётся само», сетка 2 × 3 плиток шаблона (TileTemplate; на плитке имя и подпись из словаря по id, «3:00 · 16:9» — из ответа сервера, кадр воспоминания на фоне), внизу кнопка-обводка «Настроить самому» → первый шаг с пустым заказом. Материала мало — вместо перехода поднимается SheetTooLittle.
АВТОПИЛОТ: тап по плитке выделяет её (обводка, остальные гаснут до 40 %), заполняет заказ из шаблона (история, треки и пожелания, длина, формат — всё из ответа сервера) и запускает мастер сам: шаг за шагом с переходом 240 мс, шкала шагов дозаливается, поля заполняются на глазах — история печатается, треки появляются в «Выбрано», ползунок едет к длине шаблона (перезажатой в предел через preview с учётом кадров шага 1) — и в конце ведёт на итог. Внизу вместо «Дальше» строка «Собираю по шаблону» и кнопка «Стоп» (ActionBar, вид автопилота). «Стоп» замирает на текущем шаге: заполненное остаётся, всё правится руками, дальше человек идёт сам («Дальше» возвращается). Ушли «Назад»/«Отмена» во время автопилота — автопилот прекращается. При системном reduce-motion — без печати, шаги проходят с паузой 400 мс. Шаблон, чей текст правили, на шаге истории становится «Свой текст» (делает TASK-216).
СТЫК: плитка «Новый ролик» на ленте воспоминания (M-24, TASK-207) сейчас ведёт в нынешний мастер — ведёт сюда; проще всего сохранить прежний маршрут входа и сделать его экраном шаблонов, тогда правка ленты не нужна. Нынешний вход и остатки старого одноэкранного мастера, которые больше никто не зовёт, удалить.
Шаблоны читаются с сервера один раз на открытие; если запрос упал — понятная ошибка с повтором, «Настроить самому» остаётся доступной.

КОНТРАКТ API (слит в main api, README «Ролики»; смотри README, здесь выжимка):
- POST /memories/:id/montages — заказ. Поля необязательные: target_seconds (целое, от min_seconds до max_seconds воспоминания), story_text, include_media_ids, exclude_media_ids, music_tracks (массив по порядку проигрывания: id полки bright|warm|calm|night|road и/или ключи своих загруженных треков music/<uuid>; пусто = без музыки — тогда в ролике живой звук видео), music_note (пожелания к трекам, ≤500, только вместе с треками, иначе 400), orientation. Старые music_track_id / music_track_key ещё принимаются — приложение их больше не шлёт. 400 на длину вне предела: {"error":"target_seconds out of range","min_seconds","max_seconds"}; 409 «мало материала»: {"ready_items","need"}.
- POST /memories/:id/montages/preview — тот же body, ничего не пишет. 200: {photos, videos, people, min_seconds, max_seconds, target_seconds, orientation, estimate_minutes}. Числа — по кадрам, которые войдут (готовые минус exclude_media_ids). Отказы те же, что у заказа. Предел длины и итог берутся ТОЛЬКО отсюда — приложение не считает их само.
- GET /memories/:id/montage-templates — только организатор. Шесть в порядке макета: {id, story_text, target_seconds, orientation, music_tracks, music_note|null}. id: for_myself, quick, report, short_form, parents, dopamine. Названия и подписи карточек шаблонов — в словаре приложения (ru и en, руками) по id; длина и формат на плитке («3:00 · 16:9») — из ответа. Длина шаблона уже зажата в предел по всему материалу; на шаге длины приложение перезажмёт её через preview с учётом исключённых кадров.
- Готовый заказ ведёт на существующий экран ролика (app/memory/[id]/montage/[montageId]) — веха M-27 превращает его в «монтаж в прямом эфире»; здесь ничего менять не нужно.
