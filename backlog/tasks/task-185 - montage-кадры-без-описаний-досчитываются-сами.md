## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Описания кадров делаются при загрузке. Если попытка упала (например, нейросеть отказала по лимиту), после трёх раз обработчик бросает кадр навсегда, и описаний у воспоминания не будет никогда — ИИ-монтаж для него не включится. Нужно, чтобы обработчик сам находил кадры без описаний и досчитывал их, как он уже делает с крупными копиями фотографий.
<!-- SECTION:DESCRIPTION:END -->
