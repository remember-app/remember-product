## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
В настройках воспоминания (макет, кнопка «Изменить название, даты и обложку») организатор правит название и даты, остальным они только видны. Обложка — кадр воспоминания, выбранный организатором; пока он не выбран, карточка в списке выглядит как сейчас. Удаления воспоминания целиком по-прежнему нет.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Организатор меняет название и даты воспоминания (начало, необязательный конец) с теми же проверками, что при создании; участник любой другой роли получает отказ, не участник — 404 как везде
- [ ] #2 Обложка — готовый кадр этого же воспоминания, выбранный организатором; её можно снять; чужой или неготовый кадр выбрать нельзя
- [ ] #3 Список воспоминаний и данные воспоминания отдают обложку (если выбрана) ссылкой на превью, как остальные картинки; без обложки ответ такой же, как сейчас
- [ ] #4 Удаление кадра, который выбран обложкой, снимает обложку и не ломает воспоминание; выход организатора и удаление воспоминания по-прежнему невозможны
- [ ] #5 Миграция получает номер выше самого большого на main на момент слияния — перед слиянием проверить ещё раз
- [ ] #6 Автотесты на права, проверки, обложку и удаление обложечного кадра зелёные
