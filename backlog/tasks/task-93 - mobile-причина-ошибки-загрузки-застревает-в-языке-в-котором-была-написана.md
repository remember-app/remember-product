## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
uploads.ts рендерит текст ошибки в момент броска и хранит готовую строку в очереди на диске (JSON). Экран загрузки просто показывает эту строку в баннере. Переключить язык или перезапустить приложение в другом языке — старая причина (например «файла больше нет на телефоне») остаётся на прежнем языке поверх уже переведённого экрана, пока не истечёт 15-секундный ретрай. Большинство причин самоочищаются ретраем, но upload.gone держится. Замечено ревьюером m-13 (TASK-86/89), сама веха его не касалась — правка требует хранить в очереди ключ+аргументы вместо готовой строки, через тип ошибки, форму очереди на диске и экран.
