## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Даты на ленте по умолчанию выключены — у правого края стержень с метками; включены — узкая щель между днями; то же для сортировки по людям. Листы фильтров и сортировки по новому макету. Экраны MemoryScrub, MemoryDated, FramesByPeople, SheetSort, SheetFilter.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Даты выключены (по умолчанию): пока лента листается, у правого края стержень с метками дат на швах между рядами, его можно тянуть; лента короче экрана — стержня нет — как MemoryScrub
- [ ] #2 Тумблер «Даты между днями» включает узкую щель 20 px между днями с «13 сентября, суббота», стержня тогда нет — как MemoryDated
- [ ] #3 Сортировка: «Сначала новые / Сначала старые», группы «Не собирать / По людям / По типу»; «По людям» — щель с аватаром, именем и числом кадров, люди по убыванию числа кадров — как FramesByPeople
- [ ] #4 Фильтры: «Кто принёс», «Тип», «День» с числом кадров и «Другая дата», живое число на кнопке «Показать N кадров», «Сбросить»; отбор или сортировка не по умолчанию — точка spark на кнопке; краевые состояния из спецификации («Показать все», «Ни одного кадра под эти условия»)
- [ ] #5 Раздела «Лейблы» в фильтрах здесь нет — его подключает веха Labels, лист оставляет для него понятное место; выбранное не хранится между запусками
- [ ] #6 Проверка типов и автотесты зелёные
<!-- AC:END -->
