СДЕЛАНО (ветка worktree-agent-a840ddd59ceee1d90 в projects/montage, коммит 82865f2; в main не сливал — за лидом).

Список треков → одна дорожка. `params.music_tracks` — список любой длины, id полки и ключи `music/<uuid>` вперемешку, порядок значимый. Разбор названий — `montage._ordered_music` (до скачивания материала, чтобы неизвестный трек отказывал так же дёшево, как раньше), файлы — `montage._music_files` (свой качается из бакета и проходит `media._refuse_playlists`, нечитаемый = отказ без повторов), склейка — `assembly.one_track`: acrossfade в секунду (`TRACK_FADE_SECONDS`), общий формат 44,1 кГц стерео на входе каждого трека, один трек в списке не пересобирается. Ритм (`rhythm.beats`) ищется по этой собранной дорожке — склейки идут в такт всему списку.

Пустой список = без музыки. `assembly.assemble(track=None)`: `_normalise(live_sound=True)` оставляет клипу его дорожку, а фотографии и клипу без звука (`_has_sound`) подкладывает тишину той же длины; `_assemble` склеивает звук `acrossfade` в те же полсекунды, что и `xfade` картинки. Ритм в этом случае не зовётся вовсе — куски держатся так, как их дали отсев или режиссёр.

Старая форма. Нет ключа `music_tracks` — читается как читалось (`music_track_key` → `music_track_id` → `warm`), повтор упавшего старого ролика собирается как собирался.

Режиссёр. `montage._music_heard` отдаёт треки по порядку с длиной каждого (свой — словами «свой трек», не ключом), `music_note` идёт рядом; `director.direct(music=…, music_note=…)` → `ai.plan_montage`, промпт PLAN дополнен. Запрос сохраняется в `ai_requests` как все. Без ключа нейросети режиссёр не зовётся — сборка как раньше.
