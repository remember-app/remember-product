## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Ревью нашло три реальные поломки на экранах вехи. «Поделиться» кадром на Android открывает пустой системный лист: файл не прикладывается (работает только на iOS). В режиме выбора щель дня выбирает весь день, но кружок в ней не показывает выбор, а повторный тап ничего не снимает. Открытие ролика из сведений о кадре кладёт в стек вторую ленту воспоминания.
