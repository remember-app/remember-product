## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
В фильтрах воспоминания появляется раздел «Лейблы»: участник отмечает один или несколько лейблов и видит в ленте только кадры, лежащие в них. Так открывается содержимое лейбла — отдельного экрана для этого нет.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 В листе фильтров третьим разделом, между «Тип» и «День», ряд чипов лейблов (спецификация 10.8.2): квадрат цвета, название, число кадров; у личного лейбла значок замка; общие без значка
- [ ] #2 Отметить можно несколько: в ленте остаются кадры, лежащие хотя бы в одном из отмеченных; это сочетается с остальными фильтрами по тем же правилам, что они сочетаются между собой
- [ ] #3 Отбор идёт на телефоне по списку лейблов у кадра, который уже приходит с галереей; чужих личных лейблов человек не видит нигде
- [ ] #4 Края: лейблов в воспоминании нет — раздела нет; выбран лейбл, из которого все кадры сняты другими фильтрами — главная кнопка недоступна с подписью «Ни одного кадра под эти условия»; «Сбросить» снимает и лейблы; точка на кнопке фильтров горит и от выбранного лейбла
- [ ] #5 Раздел обновляется после того, как лейблы завели, переименовали, удалили или положили в них кадры, без перезапуска; удалённый лейбл выпадает из отмеченных
- [ ] #6 Слова — из макета и strings.ts на всех языках; вид — из деталей кита (Раздел «Лейблы» в фильтрах, деталь 73); типы и тесты mobile зелёные, правила отбора покрыты тестами
- [ ] #7 Раздел «Лейблы» в фильтрах работает в тёмной и светлой теме: цвета только из токенов кита, подстановкой по образцу HomeDay (слово chief 2026-09-21), свои цвета не заводятся
<!-- AC:END -->
