## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Сделано (коммит 1d0f2e4, смержен в api/dev): montages.name (текст, необязателен при заказе; если пуст — сервер сам подставляет «Ролик на N:NN»/«Movie of N:NN» по длине, вычисляется при чтении, не хранится как ярлык). PATCH /memories/:memoryId/montages/:montageId {name} — переименование, только организатор, в любой момент. POST .../montages/:montageId/watched — фиксирует факт просмотра (participant, не только организатор); GET .../montages отдаёт watched_by (только текущие участники). DELETE .../montages/:montageId — только организатор, удаляет файлы из R2 (best effort), джобу, журнал, разметку кадров и отметки просмотра каскадом. Миграция 160 (montage-name-watched). Тесты прогнаны на временном Postgres (Docker Desktop на машине завис — независимая проблема окружения), 206/226 зелёных, все 20 падений воспроизводятся и на неизменённом HEAD (нет MinIO + one case-folding тест), новых регрессий нет. doc-03 дополнен отдельной задачей.
