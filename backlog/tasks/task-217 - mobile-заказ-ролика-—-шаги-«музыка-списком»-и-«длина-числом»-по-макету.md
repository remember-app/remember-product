## Description

Третий и четвёртый шаги заказа по обновлённому макету: сколько угодно треков (или без музыки, с живым звуком видео) с пожеланием, как их использовать, и длина ролика числом секунд с ползунком, ±5 с и пределом, который считает сервер.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Шаг музыки: без треков — выбрана карточка «Без музыки»; с треками — блок «Выбрано» с суммой длин, крестиком, порядком, который меняется перетаскиванием, и полем «Как использовать треки»; убрал последний трек — возвращается «Без музыки»

- [x] #3 Заказ уходит с треками списком в том порядке, как их расставили, и с пожеланиями только при треках
- [x] #4 Шаг длины: число и ползунок двигают длину любым числом секунд, ±5 с и пять пресетов работают; предел и минимум приходят от сервера с учётом снятых кадров и обновляются при смене выбора; сверх предела ручка не идёт, пресеты сверх предела недоступны
- [x] #5 Подпись «из шаблона …» стоит, пока длину задал шаблон, и пропадает при ручном движении; формат выбирается сегментами
- [x] #6 Экраны собраны из деталей кита без своих цветов и проверены на обе темы — светлая подстановкой токенов по образцу HomeDay
