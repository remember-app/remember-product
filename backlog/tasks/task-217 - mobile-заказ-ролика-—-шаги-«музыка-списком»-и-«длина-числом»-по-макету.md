## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Третий и четвёртый шаги заказа по обновлённому макету: сколько угодно треков (или без музыки, с живым звуком видео) с пожеланием, как их использовать, и длина ролика числом секунд с ползунком, ±5 с и пределом, который считает сервер.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Шаг музыки: без треков — выбрана карточка «Без музыки»; с треками — блок «Выбрано» с суммой длин, крестиком, порядком, который меняется перетаскиванием, и полем «Как использовать треки»; убрал последний трек — возвращается «Без музыки»

- [ ] #3 Заказ уходит с треками списком в том порядке, как их расставили, и с пожеланиями только при треках
- [ ] #4 Шаг длины: число и ползунок двигают длину любым числом секунд, ±5 с и пять пресетов работают; предел и минимум приходят от сервера с учётом снятых кадров и обновляются при смене выбора; сверх предела ручка не идёт, пресеты сверх предела недоступны

ШАГ 3 «Под что монтировать»: пусто — наверху карточка-выбор «Без музыки» («Только живой звук из видео»), выбрана по умолчанию; добавил трек — её место занимает блок «Выбрано» (заголовок «N трека · M:SS» по сумме длин; строки трека с волной и крестиком; порядок меняется перетаскиванием — строка берётся за волну; внизу поле «Как использовать треки»); убрал последний — блок исчезает, возвращается «Без музыки», пожелания чистятся. Ниже блок «Музыка»: пунктирная «Свой трек» (загрузка своего трека уже есть — src/music.ts) и пять строк библиотеки (RowTrack) — у выбранных правая кнопка accent с галочкой, у остальных плюс; «Послушать» у трека библиотеки уже есть (TASK-172) — сохранить. Треков сколько угодно; блок растёт, экран скроллится.
ШАГ 4 «Как собрать»: LengthSlider — крупное число, ползунок, −5 с / +5 с, пять пресетов (0:30 · 1:00 · 1:30 · 3:00 · «Всё»), справа над блоком «до M:SS» — предел; концы «0:10» и «M:SS · всё, что есть». Предел и минимум приложение берёт из preview сервера (min_seconds / max_seconds) с учётом снятых кадров — не считает само; при смене выбора кадров предел перечитывается и длина зажимается. Ручка упирается в предел; пресеты сверх предела недоступны; материала на 40 с — предел 0:40. Если длину задал шаблон — под числом «из шаблона «…»», ручное движение подпись убирает. Формат — сегменты «Горизонтальный · Вертикальный». Кнопка «К итогу».
Старые три круглых ответа по длине (30/60/120) и одиночный выбор трека уходят из мастера; пока не готов итог (соседняя карточка), «К итогу» ведёт туда, куда вёл последний шаг мастера, — заказ проходит до конца.

КОНТРАКТ API (слит в main api, README «Ролики»; смотри README, здесь выжимка):
- POST /memories/:id/montages — заказ. Поля необязательные: target_seconds (целое, от min_seconds до max_seconds воспоминания), story_text, include_media_ids, exclude_media_ids, music_tracks (массив по порядку проигрывания: id полки bright|warm|calm|night|road и/или ключи своих загруженных треков music/<uuid>; пусто = без музыки — тогда в ролике живой звук видео), music_note (пожелания к трекам, ≤500, только вместе с треками, иначе 400), orientation. Старые music_track_id / music_track_key ещё принимаются — приложение их больше не шлёт. 400 на длину вне предела: {"error":"target_seconds out of range","min_seconds","max_seconds"}; 409 «мало материала»: {"ready_items","need"}.
- POST /memories/:id/montages/preview — тот же body, ничего не пишет. 200: {photos, videos, people, min_seconds, max_seconds, target_seconds, orientation, estimate_minutes}. Числа — по кадрам, которые войдут (готовые минус exclude_media_ids). Отказы те же, что у заказа. Предел длины и итог берутся ТОЛЬКО отсюда — приложение не считает их само.
- GET /memories/:id/montage-templates — только организатор. Шесть в порядке макета: {id, story_text, target_seconds, orientation, music_tracks, music_note|null}. id: for_myself, quick, report, short_form, parents, dopamine. Названия и подписи карточек шаблонов — в словаре приложения (ru и en, руками) по id; длина и формат на плитке («3:00 · 16:9») — из ответа. Длина шаблона уже зажата в предел по всему материалу; на шаге длины приложение перезажмёт её через preview с учётом исключённых кадров.
- Готовый заказ ведёт на существующий экран ролика (app/memory/[id]/montage/[montageId]) — веха M-27 превращает его в «монтаж в прямом эфире»; здесь ничего менять не нужно.
