## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Человек 2026-09-08: сейчас, если ключи почты не заданы, сервер пускает без письма любой адрес — достаточно того, что режим не боевой. Так быть не должно. Обход разрешён только для адресов на домене test.com и только когда режим разработки включён явным признаком; если этот признак не задан — обхода нет вообще, независимо от того, настроена почта или нет. Иначе забытая переменная на чужой машине превращается в открытую дверь. Замок закрепить тестами: обычный адрес в дев-режиме не проходит, адрес на test.com без включённого признака не проходит, в боевом режиме не проходит ничего.
