## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Мастер заказа ролика переходит на новый контракт сервера — музыка списком, длина любым числом, итог, шаблоны — и получает первые два шага по обновлённому макету: какие кадры взять (с листом «что сняли автоматически») и история ролика.
<!-- SECTION:DESCRIPTION:END -->

Нынешний мастер — src/app/memory/[id]/order.tsx (780 строк) и src/montage.ts (модель заказа и тело запроса) — собран на прошлой версии макета; заменяется по частям вехи, эта карточка — фундамент и первые два шага.

ЧТО ВХОДИТ:
1. Модель заказа v2 (src/montage.ts, src/api.ts): кадры (снятые рукой / возвращённые из автоотсева), история, шаблон (id или нет; правка текста делает шаблон «своим»), треки — упорядоченный СПИСОК (id полки или свой ключ+имя), пожелания к трекам, длина — любое целое число секунд (не тройка 30/60/120), формат. Тело запроса: exclude_media_ids = снятое автоматом минус возвращённое плюс снятое рукой; music_tracks шлётся всегда (пусто = без музыки); music_note — только при непустом списке. Клиенты api: получить шаблоны, итог заказа (preview), заказать — типы и вызовы по контракту ниже. Подпись про музыку на карточке ролика (src/memory/films.tsx) читает params.music_tracks (у новых заказов поля music_track_id/key уже нет), старые строки — как раньше.
2. Каркас мастера на ките: шапка WizardBar («Шаг N из 4», «Отмена», «Назад»), навигация шагов; экраны следующих карточек (музыка, длина, итог, шаблоны) втыкаются в него — придумай структуру маршрутов так, чтобы они не правили один и тот же файл.
3. Шаг 1 «Какие кадры взять» по макету: сетка 3×117 с кружками, снятое автоматом приглушено и с причиной, снятое рукой — кружок с крестиком; строка «Возьмём N из M · K сняли автоматически» и «Что сняли»; SheetRejected (три причины с «Вернуть», «Вернуть все K», «Оставить как есть»); кнопка «Дальше — N кадров»; сняли всё — кнопка недоступна и подпись «Оставьте хотя бы один кадр».
4. Шаг 2 «Как смонтировать этот ролик» по макету: плашка шаблона (или нет), длинное поле с историей (потолок — как сейчас в приложении, 600), правка текста шаблона меняет плашку на «Свой текст», «Дальше»; шаг можно пропустить.
Материала мало (меньше трёх кадров) — мастер не открывается, поднимается SheetTooLittle (уже есть) — как сейчас.

ЧЕГО НЕ ДЕЛАТЬ: шаги 3–4 и итог — соседние карточки; пока их нет, мастер в этой ветке должен оставаться рабочим (старые шаги живут на новой модели заказа) — заказ проходит до конца.

КОНТРАКТ API (слит в main api, README «Ролики»; смотри README, здесь выжимка):
- POST /memories/:id/montages — заказ. Поля необязательные: target_seconds (целое, от min_seconds до max_seconds воспоминания), story_text, include_media_ids, exclude_media_ids, music_tracks (массив по порядку проигрывания: id полки bright|warm|calm|night|road и/или ключи своих загруженных треков music/<uuid>; пусто = без музыки — тогда в ролике живой звук видео), music_note (пожелания к трекам, ≤500, только вместе с треками, иначе 400), orientation. Старые music_track_id / music_track_key ещё принимаются — приложение их больше не шлёт. 400 на длину вне предела: {"error":"target_seconds out of range","min_seconds","max_seconds"}; 409 «мало материала»: {"ready_items","need"}.
- POST /memories/:id/montages/preview — тот же body, ничего не пишет. 200: {photos, videos, people, min_seconds, max_seconds, target_seconds, orientation, estimate_minutes}. Числа — по кадрам, которые войдут (готовые минус exclude_media_ids). Отказы те же, что у заказа. Предел длины и итог берутся ТОЛЬКО отсюда — приложение не считает их само.
- GET /memories/:id/montage-templates — только организатор. Шесть в порядке макета: {id, story_text, target_seconds, orientation, music_tracks, music_note|null}. id: for_myself, quick, report, short_form, parents, dopamine. Названия и подписи карточек шаблонов — в словаре приложения (ru и en, руками) по id; длина и формат на плитке («3:00 · 16:9») — из ответа. Длина шаблона уже зажата в предел по всему материалу; на шаге длины приложение перезажмёт её через preview с учётом исключённых кадров.
- Готовый заказ ведёт на существующий экран ролика (app/memory/[id]/montage/[montageId]) — веха M-27 превращает его в «монтаж в прямом эфире»; здесь ничего менять не нужно.
