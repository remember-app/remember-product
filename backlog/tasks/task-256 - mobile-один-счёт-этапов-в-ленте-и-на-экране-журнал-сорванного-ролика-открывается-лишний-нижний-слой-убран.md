## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Решения chief 2026-09-24 (п.1, 4, 7). Сейчас карточка в ленте пишет число завершённых этапов («1 из 5»), экран — текущий («Этап 2 из 5»); в спеке design/spec.md для обоих примеры «3 из 5». README там); тесты, которые кодируют старое поведение, правит кодер, независимый прогон потом — у тестировщика.
