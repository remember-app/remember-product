## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Тап по кадру в просмотре убирает весь интерфейс — остаётся только сам кадр. Второй тап интерфейс возвращает.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Тап по самому кадру прячет шапку, ленту и нижние панели — остаётся только кадр
- [ ] #2 Второй тап по кадру возвращает интерфейс на место
- [ ] #3 Прятавшийся интерфейс возвращается по любому жесту назад — смаху, листанию ленты
- [ ] #4 Тап не мешает жестам: свайп по кадру влево-вправо листает, а не прячет
- [ ] #5 Видео на тап играет и встаёт на паузу, а не прячет интерфейс
- [ ] #6 Автотесты зелёные
- [ ] #7 Интерфейс, спрятанный тапом, возвращается тапом и смахиванием по самому кадру; этого хватает. Отдельным жестом лента не вернётся и не должна: когда интерфейс скрыт, ленты нет, вернуть её листанием физически нечем. Слова человека (doc-12) этого и требуют: «весь худ должен пропасть и оставаться только фотка, а при повторном клике вновь появляется».
<!-- AC:END -->
