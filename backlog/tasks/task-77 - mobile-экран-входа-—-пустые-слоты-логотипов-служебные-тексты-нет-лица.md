## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Пять находок дизайнера по экрану входа.

1. Пунктирные слоты Apple/Google убраны. Настоящие знаки не рисовал: их берут только из наборов провайдера, а для Apple знак приходит вместе с AppleAuthenticationButton — это отдельная работа под App Store review, и в кнопке уже висит ponytail-пометка про неё. Пунктирный квадрат остаётся слотом в демо кита; кнопка провайдера больше не подставляет его сама, проп brand ждёт настоящий знак.
2. Ошибка «mail not configured» переписана: экран отвечает на 503 своими словами — «We can’t send sign-in links right now — try again later.» (с большой буквы, с точкой, без серверной терминологии).
3. Строка «In dev it is printed in the API log» удалена — dev-флага в коде нет и заводить его ради одной строки не стал.
4. Кода не потребовалось: подсветка по фокусу (ember-граница, приподнятый фон) уже реализована в src/kit/field.tsx и работает — проверил на симуляторе, скриншот сфокусированного поля есть.
5. Сверху экрана — перфорация RailH (как на главной) и имя продукта Remember заголовком display; прежний заголовок «Sign in» убран, чтобы на экране остался один display, как требует кит.

Проверено на своём симуляторе (iPhone 16e, Expo Go, Metro на 8083 из ворктри). typecheck и 64 теста зелёные, origin/main влит без конфликтов. Коммит 8f61886 в ветке worktree-agent-aa932983895f409b4.

Мимо задачи: тот же экран показывает слова сервера при 502 («mail delivery failed») — в критерии этого не было, не трогал.
