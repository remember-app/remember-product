## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Живой прогон показал: в журнале ai_requests нет числа токенов — воркер выбрасывает счётчик поставщика, и стоимость роликов посчитать нельзя. Первые настоящие деньги владельца — счёт должен быть виден.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Если ответ поставщика содержит число токенов (у Gemini — usageMetadata: вход, выход, всего), оно записывается в журнал запросов рядом с ответом (в существующую строку, без потери прежних полей) — для всех трёх видов вызовов (описание кадров, расшифровка речи, режиссёр) и для обоих поставщиков, где они это отдают; нет в ответе — поле пустое, а не выдуманное
- [ ] #2 Схема журнала меняется только совместимо: существующие строки и API чтения журнала (если он есть) не ломаются; схема накатывается идемпотентно на существующую базу; в журнале по-прежнему нет байтов медиа и ключей
- [ ] #3 Автотесты покрывают: ответ с usageMetadata → токены записаны; ответ без них → пусто; ошибка поставщика → строка закрыта как раньше; docs/ai.md описывает поле и запрос «сколько ушло за сутки/за ролик»
<!-- AC:END -->
