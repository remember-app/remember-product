## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Общий лейбл: переименовать, перекрасить, удалить, вынуть из него любые кадры и положить в него кадры может любой участник воспоминания, зритель тоже; для этого не нужно быть ни создателем лейбла, ни организатором, ни тем, кто положил кадр

- [ ] #3 Завести лейбл: как раньше — зритель заводит только личные, остальные участники любые; смена «общий ↔ личный» после создания по-прежнему отказ; выход и исключение участника (личные уходят, общие остаются за организатором) не изменились
- [ ] #4 Правило живёт в одном месте (labelDenial); поля can_edit и can_add_media в списке лейблов говорят правду по новому правилу; пометка «ВРЕМЕННО, по decision-12» из кода, тестов и README ушла — правило решённое
- [ ] #5 Автотесты снаружи (через HTTP) переписаны под правило: посторонний по роли участник и зритель правят общий лейбл; чужой личный — «не найдено» для всех; весь набор api зелёный в своей тестовой базе
- [ ] #6 README API описывает новое правило вместо временного; то, что после замены стало мёртвым (проверки «создатель / организатор / положивший», параметр added_by у правила), убрано; подпись added_by в связи остаётся записанной, миграций нет
