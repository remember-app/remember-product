## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Лист «Сведения о кадре» (doc-02): по одному кадру сервер отдаёт кто принёс и когда, имя файла и размер, размеры в пикселях, камеру и место съёмки, и в каких готовых роликах кадр стоит и на какой секунде. Имя файла приходит с телефона при загрузке; камеру и место читает из файла воркер, раскладку по роликам записывает воркер при сборке — серверная часть заводит для этого поля и таблицу и отдаёт всё одним маршрутом.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Маршрут по одному кадру отдаёт: кто принёс (ник, имя) и сколько всего кадров этот человек принёс в воспоминание, когда принёс, время съёмки, имя файла, размер в байтах, ширину и высоту, камеру, место, список «в каких роликах» (ролик и секунда начала); читает любой участник воспоминания, включая зрителя, не участнику — 404 как везде
- [ ] #2 Заявка на загрузку принимает необязательное имя файла и хранит его; у старых кадров без него маршрут просто не отдаёт это поле и не падает
- [ ] #3 В хранилище есть место для того, что запишет воркер: модель камеры со сведениями об оптике, координаты места, раскладка кадра по роликам (ролик, секунда начала, длительность); в список «в каких роликах» попадают только готовые ролики этого же воспоминания
- [ ] #4 Миграция получает номер выше самого большого на main на момент слияния — перед слиянием проверить ещё раз, другие вехи тоже заводят миграции
- [ ] #5 Автотесты на права, на кадр без данных и на кадр в двух роликах зелёные
