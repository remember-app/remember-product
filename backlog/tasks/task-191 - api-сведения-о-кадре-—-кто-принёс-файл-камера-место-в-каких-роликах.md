## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Лист «Сведения о кадре» (doc-02): по одному кадру сервер отдаёт кто принёс и когда, имя файла и размер, размеры в пикселях, камеру и место съёмки, и в каких готовых роликах кадр стоит и на какой секунде. Имя файла приходит с телефона при загрузке; камеру и место читает из файла воркер, раскладку по роликам записывает воркер при сборке — серверная часть заводит для этого поля и таблицу и отдаёт всё одним маршрутом.
<!-- SECTION:DESCRIPTION:END -->

Что сделано по критериям:

1. `GET /memories/:memoryId/media/:mediaId` (`src/media/frame.ts`) отдаёт одним ответом: `uploaded_by` (id, ник, имя и `media_count` — сколько кадров человек принёс в это воспоминание), `created_at` (когда принёс), `captured_at`, `file_name`, `size_bytes`, `width`/`height`, `camera_model`/`focal_length_mm`/`aperture`, `latitude`/`longitude`, `montages` (ролик, его длительность, `start_seconds`). За `app.authenticate` + `app.requireMembership`, читает любой участник включая зрителя; не участник, чужой кадр, кривой id и `pending_upload` — общий 404. Ссылок не подписывает, хранилище не спрашивает — 503 у маршрута нет.
2. Заявка на загрузку принимает необязательный `file_name` (до 255 символов) и хранит его; у кадров без имени маршрут не отдаёт ключ вовсе (не пустую строку) и не падает. Вырезается только NUL.
3. Миграция 100: `media_items.file_name`, `camera_model`, `focal_length_mm`, `aperture`, `latitude`, `longitude` и таблица `montage_frames` (montage_id, media_id, start_seconds, duration_seconds, created_at; PK по первым трём, индекс по media_id). В «в каких роликах» попадают только `ready`-ролики этого же воспоминания.
4. Номер 100 — выше максимального на main (090) на момент последней проверки перед попыткой слияния. Соседние вехи миграций пока не завели; **лиду перед слиянием проверить номер ещё раз** и при коллизии перенумеровать пару 100.do/100.undo.
5. Шесть автотестов в `src/media/frame.test.ts`: права (участник/зритель/чужой/без сессии), кадр без данных, кадр в двух готовых роликах (упавший и ролик чужого воспоминания в список не попадают), полный набор сведений со счётчиком кадров, имя файла через заявку. Весь прогон: 107 тестов зелёные, tsc чист.
