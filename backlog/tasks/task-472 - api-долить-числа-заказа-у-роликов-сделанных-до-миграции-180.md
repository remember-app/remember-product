## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Ролик в очереди показывает, что заказано: сколько фото и сколько видео. Эти числа api считает один раз при заказе и пишет в колонки montages.photos и montages.videos — их завела миграция 180. У роликов, заказанных до неё, чисел просто нет, и приложение не рисует плитку «Кадров», хотя заказ и материал на месте.

Что входит: пересчёт того, что можно восстановить, — сколько фото и видео было в заказе, по тому, что записано в самом заказе и по материалу на момент его. Там, где восстановить нельзя, честное отсутствие значения, а не выдуманный ноль и не догадка.

Вне этого шага: поля, которые появляются только по ходу сборки, — темп чужого трека и оценка времени у упавшего ролика. Их в базе нет и не должно быть, приложение не рисует поле, пока у него нет значения.
