## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
В листе «Сведения о кадре» место показывается названием («Усадьба «Остафьево»», улица, город): координаты из файла приложение переводит во встроенном в телефон определителе адреса, без внешних сервисов, ключей и денег. Сервер по-прежнему отдаёт только координаты.
