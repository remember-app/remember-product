## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Если вход человека перестал действовать (вышел с другого телефона, кончился срок), приложение не понимает этого посреди работы: экраны продолжают спрашивать сервер, а журнал монтажа говорит «Связь пропала». Нужно одно понятное поведение во всём приложении.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Ответ «не вошли» (401) на любой запрос приложения ведёт к одному и тому же поведению во всём приложении: вход сбрасывается и человек попадает на экран входа; экраны не опрашивают сервер бесконечно
- [ ] #2 Журнал монтажа, галерея, лента роликов и другие опрашивающие экраны при 401 перестают опрашивать; «нет связи» остаётся только для обрыва связи и 5xx
- [ ] #3 Есть тесты на записанных ответах; полный набор и типы приложения зелёные
