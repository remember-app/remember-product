## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Чтобы сверять приложение с макетом по картинке, нужно уметь в симуляторе iOS вызвать любой из 57 экранов макета в том же состоянии и снять его. Собирается стенд: подставной сервер с данными, вход в каждое состояние (маршрут, лист, режим), снимки в размере экрана макета.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Для каждого из 57 экранов макета есть способ вызвать его в приложении в том же состоянии (маршрутом, открытием листа, режимом) и снять скриншот симулятора; список пар «экран макета — состояние приложения» с пометкой, какие вызвать не удалось и почему
- [ ] #2 Подставной сервер отдаёт данные, похожие на данные макета (воспоминания, участники, кадры-заглушки из design/img, ролики, журнал), и не трогает базу, очередь, хранилище и процессы человека; работает на своём порту
- [ ] #3 Стенд воспроизводим: один скрипт поднимает сервер и приложение и снимает все состояния; описание запуска, устройства (модель, iOS), способа нажатий и ввода; снимки — в размере экрана макета (390×844) с указанием масштаба
<!-- AC:END -->
