## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Люди переезжают с экрана воспоминания в его настройки: обложка, название, даты, люди со статусами, «Зрители» отдельным блоком, «Пригласить» внизу. Свой статус участник меняет в любой момент (doc-06). Организатор правит название, даты и обложку. Экран MemorySettings, режим «Править состав», SheetConfirmMember.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Отдельный экран по маршруту memory/[id]/settings как MemorySettings: карточка события (обложка, название, «даты · N кадров»), блок «Люди» с «N из M всё скинули», строки участников со статусом знаком справа и числом кадров, блок «Зрители» отдельно (зрителей нет — блока нет), «Пригласить» внизу с уже существующим листом приглашения
