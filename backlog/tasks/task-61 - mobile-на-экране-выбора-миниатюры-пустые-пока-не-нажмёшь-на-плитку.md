## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Со слов человека: «не отображаются картинки пока не кликнешь на них при загрузке». На экране выбора медиа плитки пустые; картинка появляется только у той, по которой нажали и которая стала выбранной.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Причина отдельная и в ките, то есть в обеих сетках сразу: кадр проявлялся Animated-непрозрачностью поверх expo-image (createAnimatedComponent + useNativeDriver). Нативный драйвер пишет прямо во вью, а expo-image — класс-обёртка вокруг нативного, поэтому значение доезжало до единицы в JS, а картинка оставалась на нуле; тап перерендеривал плитку и коммитил уже доехавшее значение — отсюда «появляется только та, по которой нажали», и появляется приглушённой. Проявление переведено на собственный transition expo-image, приглушение выбранного — обычный стиль. Коммит 6a2c346 (ветка worktree-agent-ac5b0410a997920c8). Автотеста нет: правка целиком в отрисовке, а рендерера в проекте нет — vitest ходит только в модули без react-native.
