## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Загрузка кадров с телефона тем же видом, что лента воспоминания: даты всегда между днями, тап по дате выбирает весь день, режим выбора включён сразу. Краевые состояния галереи и очереди. Вопрос «Это всё?» после отправки ставит статус участника. Экраны Upload, UploadAccess, UploadLimited, UploadQueue, UploadEmpty, SheetAskAll.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Как Upload: стеклянная шапка (назад · капсула «Ваши кадры» / «в «имя воспоминания»» — не кнопка · включённая круглая кнопка режима выбора), лента 3 в ряд с щелью 2 px, между днями щель с датой-кнопкой и счётчиком: тап по дате выбирает весь день (пустой кружок → с галочкой), повторный тап снимает; внизу «Отправить N файлов», недоступна, пока ничего не выбрано
- [ ] #2 Режим выбора включён с начала; выключили — кружки уходят, лента просто листается, тап по кадру открывает его во весь экран
- [ ] #3 Состояния: нет доступа к галерее (UploadAccess), доступ частичный (UploadLimited), галерея пуста (UploadEmpty), отправка идёт и застрявшие файлы по одному (UploadQueue)
- [ ] #4 После отправки — «Это всё?» (SheetAskAll): «Больше ничего» ставит «Всё загрузил», «Ещё будет» — «Планирует загрузить» (маршрут статуса на сервере)
- [ ] #5 Заявка на загрузку присылает серверу имя файла (нужно для «сведений о кадре»); очередь и докачка работают как раньше
- [ ] #6 Проверка типов и автотесты зелёные
- [ ] #7 Светлая тема: экран собран из деталей кита без своих цветов и в светлой теме выглядит по образцу HomeDay — подстановкой токенов; проверка на обе темы есть, как у соседних экранов (слово chief 2026-09-21: отдельной вехи под светлую тему не будет)
