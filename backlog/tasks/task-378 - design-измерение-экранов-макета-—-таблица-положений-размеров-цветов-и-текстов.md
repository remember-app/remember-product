## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Для визуальной сверки приложения с макетом нужна измеренная правда: по каждому из 57 экранов и компонентов макета — положения, размеры, отступы, цвета и тексты ключевых элементов при размере 390×844 (компоненты-листы — в своём размере). Экспорт макета — обычные страницы, измеряются безоконным браузером.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 По каждому экрану макета (design/screens/*.html, 57 штук) есть файл с элементами: роль/название, текст, положение и размер (x, y, ширина, высота в точках), шрифт (семейство, кегль, вес, межстрочный), цвет текста и фона, скругление, обводка; плюс скриншот экрана в размере макета; порядок элементов сверху вниз совпадает с порядком в макете
- [ ] #2 Измерения получены отрисовкой макета в безоконном браузере (скрипт Node + playwright-core headless, шрифты макета загружены — Unbounded, Onest), а не чтением HTML; повторный прогон даёт то же
- [ ] #3 Сводка: список экранов с пометкой, что на них произвольного содержания (фото-заглушки, цифры «подставлены руками») и что сверять нельзя; какие экраны имеют состояния, которые приложение должно повторить (пустые, загрузка, ошибка)
<!-- AC:END -->
