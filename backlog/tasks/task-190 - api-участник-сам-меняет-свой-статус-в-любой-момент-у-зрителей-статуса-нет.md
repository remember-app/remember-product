## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
В настройках воспоминания (doc-06) каждый участник в любой момент ставит себе «Планирует загрузить», «Всё загрузил» или «Ждать нечего»; сейчас сервер принимает только два последних и вернуться назад нельзя. Зрители — отдельная группа без статуса: в сводку не входят и статуса себе не ставят. Список людей отдаёт всё, что нужно экрану настроек.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Организатор и участник с правом «Добавление» меняют свой статус на любой из трёх в любой момент, в том числе из «Всё загрузил» и «Ждать нечего» обратно в «Планирует загрузить»; чужой статус поменять нельзя
- [ ] #2 У зрителя статуса нет: в списке людей у него нет статуса, попытка его поставить отклоняется, в сводку «N из M» он не входит
- [ ] #3 Список людей воспоминания отдаёт по каждому роль, статус и число кадров, которые человек принёс; зрители различимы по роли
- [ ] #4 Действующее правило автоматической смены статуса при загрузке (doc-06, TASK-110) не сломано
- [ ] #5 Автотесты на каждое из правил зелёные
