## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
В тексте шаблона ролика и на экране итога перед монтажом фраза «кадры от N человек» считала по-разному: в шаблоне — всех участников, на итоге — тех, кто принёс кадры. Решение chief 2026-09-24: считаем людей, чьи готовые кадры реально лежат в материале заказа; не принёсшие и зрители не в счёте; на обоих экранах одно и то же число.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Число «от N человек» в тексте шаблона и на итоге заказа берётся из одного места и считает только людей с готовыми кадрами, вошедшими в выборку; участники без кадров и зрители не в счёте
- [ ] #2 Тест на одном и том же воспоминании (есть участник без кадров и зритель) показывает, что шаблон и итог называют одно число; при исключении кадров число на итоге считается по оставшимся
- [ ] #3 Отдельный запрос числа людей в шаблонах убран, если он больше не нужен; весь набор тестов api зелёный (без параллельности по файлам, в своей базе)
<!-- AC:END -->
