## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Загруженное показывается галереей воспоминания всем участникам; своё медиа удаляет каждый, любое — организатор; при выходе или исключении участника всё, что он загрузил в это воспоминание, уходит вместе с ним — оригиналы и деривативы из R2, счётчики вниз, задачи из очереди сняты. Закрывает последний открытый компонент doc-01.
