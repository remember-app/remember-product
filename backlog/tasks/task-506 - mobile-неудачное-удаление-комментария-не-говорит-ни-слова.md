## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Найдено на ревью m-32. `src/screens/memory/frame-comments.tsx:86`, удаление комментария.

`catch` пустой:
```js
} catch {
  // The api refused, so the comment is still there and the sheet stays up over it
}
```

Когда сервер отказывает (404, мёртвая сессия, нет связи) **экран не меняется ничем**: лист остаётся,
комментарий остаётся, ни одной строки не появляется. Человек нажал «Удалить» и видит картину, на
которой ничего не произошло, — значит, нажимает ещё раз, и так бесконечно.

В отправке это сделано правильно: текст остаётся, рамка красная, тихо «Не отправилось — нет связи»
(решение человека №6). С удалением — тишина.

**Почему это не символично.** Во всём остальном коде отказ говорит: `errorMessage(e)` встречается
около сорока раз, `app/memory/[id]/mine.tsx:184` делает `setDropFailed(errorMessage(failure))`.
Здесь единственное место, где отказ не виден.

**Что делать.** `ConfirmSheet` (`src/kit/confirm.tsx`) места под ошибку не имеет вообще — проверил
`ConfirmProps`. Значит, правка затрагивает кит: добавить в лист слот ошибки и передавать в него
текст отказа. Какой текст — тот же негромкий тон, что у «Не отправилось», из решения человека №6:
экран говорит тихо, но говорит.

Не выдумывать новый экран: лист уже поднят, вопрос уже задан, человек уже подтвердил — ему не
хватает одной строки под словами.
