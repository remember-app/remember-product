## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Кит показывает выбор кадров как оверлей поверх «Кадров»: закрывается крестиком, а не стрелкой назад; медиатека разбита на дни съёмки, у каждого дня своя строка с датой и своим «Выбрать все N», дни события — первыми (раздел «Экраны» кита, пункт 7). Сейчас экран закрывается стрелкой назад, а медиатека — одна лента с одной кнопкой «выбрать всё за событие» над ней.
