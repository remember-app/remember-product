## Description

Прочитать раздел кита целиком перед вёрсткой, включая dl.kit-spec под макетами — там расписаны все края: одно поле делает и поиск по списку, и добавление по нику; строка того же вида, что row-member в участниках, без роли и вклада; удаление — крестик без листа подтверждения, строка гаснет и 5 секунд держит «Вернуть».

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Сделано в projects/mobile, слито в main: 25942e9 (merge), сама работа — e740b6a.

Новый маршрут /contacts по киту («Экраны» 9) и вход в него — значок людей в шапке
«Воспоминаний» слева от профиля; профиль остаётся крайним, два значка это потолок кита.

Одно поле в шапке делает обе работы: набранное сужает сохранённый список под ним, а если
точного совпадения среди своих нет — спрашивается GET /users, и найденный приходит отдельной
строкой под «Не в контактах» с «Сохранить». Сохранённый переезжает в список на месте, поле
держит набранное. Уже сохранённого ник не задваивает: точное совпадение отвечает списком, api
не спрашивается.

Крестик убирает без ConfirmSheet: DELETE уходит сразу, строка остаётся на своём месте, гаснет
именем (кит `.row-member--gone`) и пять секунд держит «Вернуть»; соседи не двигаются, «Вернуть»
переотправляет POST по нику самой строки — набирать заново нечего. По истечении пяти секунд
строка схлопывается.

Состояния: загрузка — спиннер на месте строк; сбой списка — полоса с «Повторить» там же; сбой
сохранения — полоса над списком, строка найденного остаётся с кнопкой; пусто — приглашение
набрать ник посередине тела; ничего не нашлось — «Ника @X в Remember нет» на месте списка.

Развилки, решённые по ходу:
- «Такого ника нет» говорится один раз: подписью под полем, пока под ним ещё есть строки, и на
  месте списка, когда список пуст. Кит называет оба места, но сказать это дважды — сказать один
  раз.
- «Убрана из контактов» из кита — про женщину; продукт пола не знает, поэтому строка говорит о
  списке: «Убрали из контактов».
- Свой ник в поле к сохранению не предлагается (api отвечает 400) и молча — «нет такого ника»
  было бы неправдой.
- Неудавшееся удаление откатывает угасание строки; 404 не откатывает — такого контакта и правда
  уже нет.

В ките добавлены две вещи, которые кит и так описывает: `gone` у строки участника и поле без
видимой подписи (accessibilityLabel остаётся).

npm run typecheck чистый, npm test — 247 зелёных на слитом main.
