## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Новый экран по киту (design/kit.html, раздел «Экраны» → 9. КОНТАКТЫ) — свой список ников, которых зовут в воспоминания повторно, без ручного набора. Спека: backlog/docs/doc-10 - Contacts.md.

Api уже есть и смёржен в projects/api main (TASK-128): POST /me/contacts {username} (404 неизвестный ник, 400 сам на себя, повтор не ошибка), GET /me/contacts (только свои), DELETE /me/contacts/:userId (404 если не было).

Кит целиком описывает экран, включая три состояния (список, набранный ник, пусто) и точку входа — новый значок «Контакты» в шапке корневого экрана «Воспоминания» (кит: 'Контакты' iconbtn слева от значка профиля). Прочитать раздел кита целиком перед вёрсткой, включая dl.kit-spec под макетами — там расписаны все края: одно поле делает и поиск по списку, и добавление по нику; строка того же вида, что row-member в участниках, без роли и вклада; удаление — крестик без листа подтверждения, строка гаснет и 5 секунд держит «Вернуть».
