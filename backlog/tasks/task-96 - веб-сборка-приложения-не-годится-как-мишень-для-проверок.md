## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Выяснено при разборе двух ложных блокеров m-12. В вебе: хранилище сессии — пустая заглушка, поэтому вход в браузере не сохраняется вовсе; сервер не отдаёт заголовков доступа для браузера, поэтому запросы из веб-сборки не уходят; список кадров ведёт себя иначе, чем на устройстве. Отсюда два «блокера», которых на телефоне нет. Либо веб чинится и становится честной мишенью, либо это пишется там, где проверяющий это увидит, чтобы не искать призраков.
<!-- SECTION:DESCRIPTION:END -->
