## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
По второму тесту на телефоне: когда человек скрывает интерфейс видео тапом по кадру, большая кнопка паузы остаётся на экране. Она должна уходить вместе с полосой, лентой и остальным интерфейсом и возвращаться со вторым тапом. В m-40 кнопку намеренно оставляли — это решение отменено словами человека.
