## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
По макету `HomeOffline` (spec 7.6, деталь 47): связь — полоса над содержимым, а не заглушка вместо
него. На экране воспоминания своего офлайн-макета нет — берём словами от `HomeOffline`, как
предписано для случая «в макете нет».

Плюс единый признак офлайна: сейчас «всё, что не ApiError = нет связи» живёт внутри `errorMessage`
(`call.ts:59-61`) и размазано по экранам. Место, где отказ становится «нет связи» против «сервер
отказал», нужно одно.

Границы: лента без сети — отдельная карточка, здесь не строить.
