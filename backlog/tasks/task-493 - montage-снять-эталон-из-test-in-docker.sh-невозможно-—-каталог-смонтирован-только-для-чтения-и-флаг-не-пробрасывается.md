## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Проверено в коде `projects/montage/test-in-docker.sh` (строки 19–26): `docker run` идёт с `-v "$PWD:/app:ro"` и пробрасывает шесть переменных (`DATABASE_URL`, пять переменных хранилища) фиксированным списком. Флага `MONTAGE_UPDATE_GOLDEN` среди них нет, а каталог смонтирован **только для чтения**.

Из этого следует ровно то, что нужно назвать прямо: **перезапись золотых снимков изнутри `test-in-docker.sh` невозможно**. Команда из брифа и из `docs/testing.md` (`MONTAGE_UPDATE_GOLDEN=1 python -m pytest tests/test_journal_golden.py`) через этот скрипт не работает: флаг не доходит до контейнера, а снимок туда не пишется. Обойти можно только отдельным `docker run` без `:ro` и с `-e MONTAGE_UPDATE_GOLDEN=1` — так и пришлось делать при TASK-468.

Почему это надо чинить именно сейчас: **на пересъёмке эталона без этого не обойтись**, а она последний шаг этапа (TASK-489). Сейчас снять эталон из контейнера штатным способом нельзя.

Что сделать: чтобы скрипт пробрасывал `MONTAGE_UPDATE_GOLDEN` (как остальные) и монтировал каталог для записи, когда флаг стоит. Либо — чтобы скрипт прямо писал, что перезапись снимков идёт отдельной командой, и этой командой пользоваться.
