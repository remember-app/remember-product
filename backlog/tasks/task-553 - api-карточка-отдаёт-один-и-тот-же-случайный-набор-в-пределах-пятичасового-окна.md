## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Человек: фотографии воспоминания на главном экране меняются каждые 5 часов. Сейчас api пересобирает случайную выборку на каждый ответ списка, а приложение перечитывает список при каждом возврате на главный экран — значит лицо карточки меняется при каждом заходе, а не раз в 5 часов. Набор должен быть устойчив внутри пятичасового окна и меняться на его границе.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Два ответа списка внутри одного пятичасового окна отдают один и тот же набор кадров карточки, в одном и том же порядке
- [ ] #2 На границе окна набор меняется
- [ ] #3 Набор по-прежнему берётся со всего воспоминания, только готовые и видимые кадры, ссылки подписаны как прежде
- [ ] #4 Проверка ломается, когда выборка снова становится случайной на каждый ответ
<!-- AC:END -->
