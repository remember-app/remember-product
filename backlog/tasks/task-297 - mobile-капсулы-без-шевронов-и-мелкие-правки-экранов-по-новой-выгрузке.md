## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Новое общее правило макета: в центральных капсулах нет шевронов, капсула сама по себе кнопка. Плюс мелкие расхождения экранов с новой выгрузкой — лента и её даты, галерея по людям, пустые состояния, просмотр кадра и видео, лист «Материала мало».
