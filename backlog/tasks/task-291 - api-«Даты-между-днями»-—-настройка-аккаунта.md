## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Сервер не хранит, показывать ли даты между днями. По новому макету это настройка аккаунта — одна на все воспоминания человека, а не свойство сортировки ленты. Сервер хранит её и отдаёт вместе с профилем.
