## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Вынести читаемые строки приложения в одно место с русским и английским набором, оба написаны руками, без машинного перевода. Язык берётся от языка телефона, есть способ переключить его программно с сохранением между запусками. Даты и числа должны идти по выбранному языку приложения, а не по системной локали устройства — сейчас src/dates.ts вызывает toLocaleDateString(undefined, ...), из-за чего русская системная локаль просачивается прямо в английский интерфейс. Экраны в этой задаче не трогаются — только инфраструктура и её тесты; экран профиля (переключатель) — отдельная задача.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
src/strings.ts — словарь: один ключ, два набора, английский задаёт форму, русский её заполняет (typecheck ловит незаполненный ключ). Русские числительные в трёх формах своей функцией, без Intl.PluralRules (нет в Hermes везде). Пока держит то, что приложение говорит вне экранов: ошибки api и downloads, состояния, повторяющиеся действия, счётчики кадров и участников, имена языков. Строки экранов приходят с TASK-86.

src/language.ts — язык: resolveLanguage() берёт первый русский или английский из списка языков телефона (expo-localization), остальное — английский. Сохранённый выбор читается один раз на старте (languageReady), setLanguage() переключает и пишет в expo-secure-store. Значение одно на всё приложение — модульная переменная, не контекст: currentLanguage() из любой функции, useLanguage()/useStrings() для компонентов через useSyncExternalStore. Фреймворка нет, как и у theme.ts.

src/dates.ts — легло поверх формы кита из TASK-80: dayFields спрашивает слово месяца у currentLanguage() вместо undefined (undefined = системная локаль устройства, из-за него русская дата стояла в английском экране). Регион не нужен: из локали берётся только слово.

Тесты — src/language.test.ts (телефон решает; ручной выбор побеждает и переживает перезапуск; незнакомый язык телефона и незнакомое сохранённое значение дают английский; язык дальше по списку телефона тоже считается), src/strings.test.ts (три формы русских числительных, ни один ключ не остался английским в русском наборе), src/dates.test.ts (день и диапазон без названной локали идут по языку приложения при телефоне на русском). npm test — 74 зелёных, npm run typecheck чист, npx expo export собирается.

Экраны и профиль не тронуты (TASK-86, TASK-90). expo-localization нативный: старый dev-билд надо пересобрать. Импорт нативных модулей в node падает на __DEV__, поэтому vi.mock добавлен и в frames.test.ts и media-window.test.ts, которые тянут @/dates.
