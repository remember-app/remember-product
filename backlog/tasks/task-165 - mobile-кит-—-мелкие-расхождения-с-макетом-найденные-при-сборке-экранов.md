## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Источник — design/spec.md разделы 2/4/7. Конкретные находки (с ссылками на файлы кита):
1. Пустое состояние (src/kit/empty.tsx): в макете промежутки круг→22→блок, внутри блока заголовок→12→абзац; кит ставит везде одинаковые 24. Видно разом на пяти экранах (HomeEmpty, FramesEmpty, ContactsEmpty, UploadEmpty, InviteDead) — почини один раз в ките.
2. Круглая кнопка кита рисует свой знак приглушённым цветом (muted) на любой заливке; в макете знак на заливке surface всегда читается основным цветом текста. Задевает шапку главного экрана и низ галереи.
3. Знак в пустом состоянии с жёлтым кольцом (spark) рисуется приглушённым цветом вместо основного.
4. У поля ввода нет варианта «на ink» — по спеке 7.3 поле внутри листа (сам лист surface) должно стоять на ink, а не наследовать surface. У Field такого варианта пока нет.
5. Точка-искра на круглой кнопке обведена цветом ink, хотя сидит на surface (спека 7.4 требует цвет подложки, на которой стоит кнопка).
6. AppBar: промежуток 12 там, где макет даёт 8; круглые кнопки в шапке не вынесены за поле экрана на −10 (спека 7.1).
Каждый пункт — точечная правка в src/kit/*, без смены API компонентов (не должна задеть экраны, которые их уже используют). После правки прогнать полный набор тестов кита — истории должны остаться зелёными.
