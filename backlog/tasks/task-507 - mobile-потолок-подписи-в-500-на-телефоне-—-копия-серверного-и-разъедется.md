## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Найдено на ревью m-32. `src/api/media.ts:29`:

```ts
export const MAX_COMMENT = 500;
```

Это руками переписанный `MAX_COMMENT_LENGTH = 500` из `projects/api/src/media/comments.ts:49`.
Два репозитория, общего источника нет, связи тестами нет.

**Чем это обернётся.** Сервер поднимет потолок — телефон по-прежнему печатает до 500, api отвечает
400, и это падает в то же красное «Не отправилось — нет связи», что человек уже видел при обрыве
связи. Настоящая причина остаётся невидимой, и чинить её будут не там.

Комментарий в коде (`media.ts:24`) говорит: «телефон держит себя тихо». Это молчание и есть
причина, по которой разъезд не всплыв бы нигде.

**Что делать.** Раз связать нельзя — репозитории раздельные, общего пакета нет, и тащить ради
одной цифры генерацию не стоит. Значит, договорённость должна быть записана так, чтобы разъезд
было видно:

- либо проверить, что api отличает «слишком длинно» от прочих отказов отдельным кодом, и телефон
  говорит про это своими словами, а не «нет связи»;
- либо убрать потолок с телефона и позволить человеку напечатать, а отказ показать как отказ.

Второе честнее: потолок нужен серверу, а телефон без него просто отправит и узнает ответ. Первое
требует изменения контракта в api — это решение не только моё, и оно выходит за пределы m-32.

Реши, пожалуйста, какой из двух путей берём; вторая карточка — про границу m-32.
