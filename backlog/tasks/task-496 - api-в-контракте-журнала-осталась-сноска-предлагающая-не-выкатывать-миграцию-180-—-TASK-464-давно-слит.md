**Решение (chief, 2026-10-04): убрать целиком, без замены на «с оговоркой».** Оговорка про то же самое через полгода снова станет неправдой — это уже случилось один раз. Если хочется оставить след — одна строка в журнле истории, а не предостережение в живом тексте.
