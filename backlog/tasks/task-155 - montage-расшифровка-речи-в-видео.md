## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Ветка worktree-agent-acaf5f3845232890f сабмодуля montage, коммит 7e130d1 (слияние в main — за лидом).

Что сделано:
- speech.py — новый обработчик очереди media_speech: качает оригинал, ffmpeg вынимает звук (моно 16 кГц AAC, -vn), расшифровка идёт через ai.AI.transcribe_speech (TASK-151), результат — в media_speech.
- schema.sql — таблица media_speech (media_id text PK = id медиа, transcript text, created_at). Столбца «кто говорит» нет намеренно (decision-11). FK на media_items нет: schema.sql должен накатываться на базу без миграций API.
- worker.py — handler media_speech в HANDLERS; media.py — в конце media_preview видео само ставит себе задачу расшифровки (INSERT в jobs; worker.enqueue недоступен — worker импортирует media).
- README — раздел «Речь в видео (media_speech)».

Решения исполнителя:
- Отдельный модуль speech.py, а не в media.py: пайплайн уже разложен по модулям (selection/assembly/ai), и это снижает конфликт при слиянии с TASK-154/158.
- Переиспользование: задача на медиа, у которого уже есть строка в media_speech, завершается сразу и в сеть не идёт (AC#4).
- Пустая расшифровка — это ответ: видео без звуковой дорожки (проверяется ffprobe -select_streams a) в нейросеть не отправляется вовсе, видео со звуком, но без речи, получает пустую строку от модели. В обоих случаях строка пишется, ошибки нет, повторно никто не спрашивается (AC#2).
- Без настроенного поставщика (сегодня) задача не пишет ничего и даже не качает оригинал — иначе каждое видео гонялось бы через хранилище и ffmpeg ради пропущенного вызова. Клип расшифруется, когда появится ключ.
- Строка пишется только если медиа ещё существует (INSERT ... WHERE EXISTS): участник может выйти и забрать материал, пока модель слушает.

Тесты: test_speech.py, 8 проверок на записанных ответах (транспорт подменён, ai.from_env подменён), без сети. Полный набор — 84 passed против живых Postgres/MinIO/ffmpeg (было 76); прогон шёл в своей базе remember_test_155, она удалена.

Осталось за рамками задачи (не делалось, не просили): догонки для видео, загруженных до появления ключа/этой задачи, — ставятся в очередь руками (python worker.py enqueue media_speech <id>), README про это говорит; при удалении медиа строка media_speech не убирается (FK нет) — если это станет важно, чистить придётся отдельной уборкой.
