## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Предел длины считает все готовые кадры, а воркер часть из них отсеет (размытые, пересвеченные): заказ на предел на таком материале выходит короче обещанного. Решение chief 2026-09-24: исключать отсеянное, когда сохранённый вердикт автоотсева уже есть; где вердикта ещё нет — предел приблизительный, это честно и так остаётся, предсказаний не выдумываем.
