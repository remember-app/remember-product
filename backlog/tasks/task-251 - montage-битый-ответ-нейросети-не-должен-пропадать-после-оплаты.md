## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Если нейросеть вернула слишком большое число или испорченный символ, ответ не записывается в журнал запросов, задача идёт на повтор и мы платим за тот же ответ второй раз.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->

- [ ] #2 Есть тест на записанных ответах, красный без исправления; сеть и живые вызовы нейросети не используются

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Найдено ревьюером воркера m-27 вне коммитов вехи. ai.py, разбор ответа: 1e999 → бесконечность, экранированный одиночный суррогат (\ud800) проходит разбор; оба потом роняют запись в журнал запросов (база не принимает; проверено в тестовой базе). Защита ловит только буквальные NaN/Infinity. Докстринг нарезки в director.py утверждает, что бесконечность отсекается — неверно. Там же: длина строкой "NaN" проходит сквозь ограничения по длине (по коду, прогоном не проверено). understanding.py: список действующих лиц строкой разбирается по буквам, метки ложатся навсегда.
