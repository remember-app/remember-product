## Description

<!-- SECTION:DESCRIPTION:BEGIN -->

**10.8.3 — правка воспоминания.** Отдельный экран MemoryEdit (шапка «Изменить воспоминание»):
поле «Название» 56, блок «Когда это было» целиком из Create (строка диапазона, быстрые чипы 36,
календарь, подпись; тумблера нет), блок «Обложка» — карточка 22 со слотом 68/14, кнопка в строке
«Выбрать»/«Заменить» и тихая «Снять обложку». Выбор кадра — лист SheetCover 640: сетка мастера
117/щель 3, кружок выбора в виде «очередь отправки», но выбор один (radiogroup). Только
организатор: у остальных карандаша нет вовсе, а не недоступен. Состояния: ничего не менялось
(«Сохранить» недоступна), сохранение (кнопка «занята», поля недоступны), ошибка (баннер связи,
набранное остаётся), имя стёрли (ошибка поля), уход с несохранёнными правками (лист-подтверждение
без предмета и без опасной кнопки). Обложка видна в трёх местах одной цепочкой: выбранный кадр →

убирает. Зрители по тем же правилам. Подтверждение — нарисованный SheetConfirmMember; у зрителя
плашки цены нет. Возврата («Вернуть», как в контактах) здесь нет намеренно.
