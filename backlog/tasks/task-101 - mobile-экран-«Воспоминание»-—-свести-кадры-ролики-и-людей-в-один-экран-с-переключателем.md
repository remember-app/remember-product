## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Кит держит воспоминание одним экраном с тремя лицами — Кадры / Ролики / Люди — под общей шапкой с именем воспоминания и переключателем segment-wide под ней (раздел «Экраны» кита, пункты 4–6). Сейчас это три разных экрана с тремя разными шапками: memory/[id].tsx (люди), memory/[id]/gallery.tsx (кадры), memory/[id]/montage.tsx (ролики). Свести к одному экрану по ките, ничего не убирая и не меняя в поведении каждого из трёх лиц. Заодно TASK-56: платформенный Switch-блок повторён слово в слово на экране создания и здесь — вынести в общий компонент.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Маршрут остался один — src/app/memory/[id].tsx: он держит только открытое лицо и само воспоминание (имя, даты, роль), прочитанное один раз на три лица, чтобы имя в шапке не мигало при переключении. Сами лица лежат в src/memory/{frames,films,people}.tsx (в src/app нельзя — там всё маршрут), общая шапка — src/memory/head.tsx. Лицо можно попросить ссылкой: ?face=films|people, по умолчанию кадры; пуш «ролик готов» и принятое приглашение переведены на это (приглашение — на «Люди», куда оно приводило и раньше). Segment кита получил wide и hideLabel по .segment-wide; слова лиц — Кадры / Ролики / Люди в обоих наборах (montage.title и members.title сменили значения, framesPlain как был). Платформенный Switch вынесен в src/kit/toggle.tsx и подключён в лист приглашения; src/app/create.tsx по указанию координатора не тронут (там параллельно идёт TASK-100) — вторая копия снимается отдельной карточкой, TASK-56 закрыт наполовину. Тесты композиции (memory-screens.test.ts) переписаны под один экран, свипы screen-theme и switch расширены на src/memory и src/kit. Проверено вживую на симуляторе (Expo Go, api на localhost): три лица в тёмной и светлой темах, ru и en; заодно найдено и починено, что ссылка ?face= на уже открытое воспоминание не переключала лицо.
