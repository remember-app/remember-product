## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Решения chief 2026-09-24 (п.2, 3, 5, 6, 8). Место кадра — факт раскладки (поле places файла в ответе журнала), а не часть мысли; сейчас его рисует только пластина мысли на листе файла (в сценарии без нейросети мыслей нет — мест не видно). Воркер пишет у «Беру» причину included (по слову организатора), приложение её не показывает — договор api называет причину только у «мимо», но воркер и словарь причин шире; словарь причин — reasonWord в src/montage-journal.ts, слова в strings.ts (ru/en). Ритм без музыки: в записи режиссёра-без-музыки итог этапа rhythm пишет cuts 0 и track [] (с музыкой — track, bpm, cuts). Значок у баннера «нет wifi» — у баннера кита есть подмена значка (параметр icon, src/kit/card.tsx ~стр. 120), сейчас никто не передаёт; строка «Вас больше нет в этом воспоминании» — s.memory.gone. Слово «Не в истории» (причина «не вошёл в ролик») оставляем как есть. Дизайнера не звать — значок выбрать из имеющихся в ките по смыслу.
