## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Впервые включить облачную нейросеть настоящим ключом человека и один раз прогнать весь живой путь: описание кадров, расшифровка речи, режиссёр монтажа. Это первые настоящие деньги — прогон на маленьком воспоминании, один ролик, со счётом запросов.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Прогнан один настоящий путь без записанных ответов: воспоминание из нескольких кадров (3–5 фото и одно короткое видео с речью) → описание кадров → расшифровка речи → режиссёр → готовый ролик; каждый из трёх вызовов нейросети ответил, ответы разобраны, ролик собран и открывается
- [ ] #2 В журнале запросов (ai_requests) по прогону: сколько было запросов каждого вида, статусы (ответ / отказ / пропуск), сколько заняло; если поставщик отдаёт число токенов — сколько токенов ушло; оценка стоимости по действующим ценам поставщика с пометкой «оценка» и с указанием модели — чтобы chief мог назвать счёт человеку
- [ ] #3 Материал маленький и не личный: кадры и видео нарисованы или озвучены на месте (например ffmpeg и штатная озвучка macOS), не фото людей; не больше одного ролика; повторов вслепую нет — если что-то упало, разобрана причина по журналу, а потом один осознанный повтор
- [ ] #4 Если живой путь показал расхождение с тем, что обещает docs (director.md, ai.md) — оно записано находкой и заведено карточкой from-lead
- [ ] #5 Работает не на стенде человека: своя временная база на том же контейнере Postgres под уникальным именем и свой временный MinIO (уникальное имя контейнера, нестандартный порт) — бакет Google для этого не нужен; сервер и обработчик подняты локально с параметрами только этого прогона; ключ нейросети взят из projects/montage/.env человека и в отчёт, карточки и репозитории не попал; после прогона объекты, временная база и контейнер убраны, процессы остановлены
<!-- AC:END -->
