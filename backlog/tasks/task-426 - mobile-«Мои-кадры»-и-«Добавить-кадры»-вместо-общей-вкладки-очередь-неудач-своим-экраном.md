## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
«Ваши кадры» разделяются на «Добавить кадры» (только выбор из галереи телефона) и новый экран «Мои кадры» — то, что уже отдано воспоминанию, своей сеткой по дням с состоянием каждой плитки (летит, не ушёл, скрыт). Неудавшиеся отправки переезжают в собственный экран очереди.
