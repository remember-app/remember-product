## Final Summary (TASK-215)

Ветка `worktree-agent-a1d3e5236ef2fb70e`, коммит `66bf542` (в main сливает лид; свежий main влит в
ветку — на момент прогона main стоял на `2c90b3a`, расхождений нет).

Размеры пишет `media_frame_info` — та же задача, что читает камеру и место: один оригинал, одно
чтение, одна догонка. `media_preview` их не пишет (заметка ponytail там снята), задачу он по-прежнему
ставит концом обработки.

- `media.py`: `FrameInfo` получил `width`/`height`; `_photo_info` меряет фото через pillow и
  применяет EXIF-поворот (`UPENDED = {5,6,7,8}`; HEIC приходит из pi-heif уже развёрнутым, тег
  сброшен в 1); `_dimensions` переведён на json-вывод ffprobe и применяет display matrix
  (`stream_side_data=rotation`); `frame_info` добирает размер через ffprobe для видео и для «фото»,
  которое pillow не открыл; `media_frame_info` пишет обе колонки в `media_items`.
- `worker.py`: условие догонки `sweep_media_without_frame_info` — `item.width IS NULL` вместо
  подзапроса по строке в `jobs`. Признаком «файл уже прочитан» стал размер: пустая камера от
  непрочитанного файла неотличима, а размер есть у всего, что попало в галерею. Так догоняются и
  кадры, прочитанные прошлой версией задачи.
- Побочно: `montage.py` зовёт ту же `_dimensions` для проверки «хватает ли копии на холст» — у
  повёрнутого оригинала она теперь меряет ту сторону, которую видит ffmpeg при раскодировании.
- README подпроекта: раздел переименован в «Размер, камера и место», добавлены колонки, правило
  поворота, новый признак догонки и как рисуются повёрнутые фикстуры.

Тесты: `test_media.py` — фото прямое и снятое боком (рисует pillow: EXIF), видео прямое и
вертикальное (ffmpeg в два прохода: display matrix переживает только `-c copy`), файл без
изображения (колонки пустые, задача `done`), догонка кадра, прочитанного до появления размеров. Весь
набор в Docker: 180 passed. Прогон шёл на своих Postgres (55433) и MinIO (59010) с накатанными
миграциями API; контейнеры, образ и временные файлы убраны, стенд человека не тронут. В сеть за
размером воркер не ходит, живых вызовов нейросети в прогоне не было.
