## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
По второму тесту на телефоне: при отправке новых файлов проверять, не загружал ли человек их раньше в это воспоминание. Повторно не загружать молча: если совпадение есть, спросить «это фото уже загружено — загрузить ещё раз?» и по «Да» отправить всё, по «Нет» — только новые. Сервер не меняется.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Работа идёт в projects/mobile; первым делом pwd и git rev-parse --show-toplevel, при несовпадении — стоп. Подход без сервера, проверен по api (projects/api/src/media/gallery.ts): список кадров воспоминания отдаёт kind, uploaded_by, size_bytes, captured_at, width, height, duration_seconds. Имени файла в списке нет — на него не опираться. width/height/duration у свежего кадра могут быть null, пока обработчик не измерил, поэтому совпадение — прежде всего вид + размер файла + дата съёмки, а размеры и длительность уточняют. Сравнивать с записями uploaded_by = текущий человек. Экран — src/app/memory/[id]/upload.tsx, шторка — kit/confirm.tsx; текст — в словарь. Один вопрос на отправку: один дубль — единственное число, несколько — счёт. Ничего не деплоить, в удалённую ветку не пушить; коммит в свою ветку ворктри и отчёт.
