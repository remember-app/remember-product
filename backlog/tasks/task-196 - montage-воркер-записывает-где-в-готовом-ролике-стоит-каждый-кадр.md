## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Чтобы лист «Сведения о кадре» показывал «в каких роликах и на какой секунде» (doc-02), воркер по завершении сборки записывает по каждому вошедшему в ролик кадру секунду начала и длительность. Таблица общая с вехой «Монтаж в прямом эфире»: журнал её не дублирует.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 После сборки на каждый кадр, вошедший в ролик, есть запись с секундой начала и длительностью, совпадающими с тем, как собран ролик
- [ ] #2 Кадры, не попавшие в ролик, записей не имеют
- [ ] #3 Повторная сборка того же заказа заменяет записи, не дублирует
- [ ] #4 Автотесты зелёные
- [ ] #5 Раскладка записывается сразу после подгонки в ритм (rhythm.fit), когда длины окончательные, — до конца сборки, чтобы живой журнал мог показать место кадра; сбой записи не ломает сборку; в список «в каких роликах» у api попадают только готовые ролики (это уже в TASK-191)
