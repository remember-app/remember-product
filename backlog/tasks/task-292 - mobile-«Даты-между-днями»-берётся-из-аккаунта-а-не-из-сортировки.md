## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
В приложении «Даты между днями» — тумблер в листе сортировки, свой у каждой ленты. По новому макету это одна настройка аккаунта на все воспоминания: из сортировки тумблер уходит, лента читает значение из аккаунта.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Лист сортировки (SheetSort) выглядит как в макете: только порядок и группировка, тумблера дат и его подписи нет, высота по макету
- [ ] #2 Лента воспоминания и лента «Ваши кадры» рисуют даты по значению из аккаунта: включено — узкая щель с датой между днями (MemoryDated, FramesByPeople), выключено — стержень у края со швами (MemoryScrub); значение одно на все воспоминания, менять его лентой нельзя
- [ ] #3 Приложение читает значение из профиля, который отдаёт сервер, и умеет его сменить запросом к серверу (клиент в src/api и хранение в профиле/контексте входа — по соседям); после смены все открытые ленты подхватывают её без перезапуска; пока значение не пришло, лента рисуется как при выключенном, а не пустой
- [ ] #4 Из состояния сортировки, её словаря и тестов убрано всё, что относилось к тумблеру; автотесты зелёные и покрывают чтение значения, смену, влияние на ленту (оба вида) и отсутствие тумблера в листе сортировки
<!-- AC:END -->
