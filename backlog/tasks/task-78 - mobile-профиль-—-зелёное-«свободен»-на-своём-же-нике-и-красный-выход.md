## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Починено в src/username-form.tsx, src/app/profile.tsx и src/strings.ts, коммит 51f3d4e.

1) Зелёное на своём нике. Корень не в экране профиля, а в общей форме ника (src/username-form.tsx), которую делят /profile и /set-username: она спрашивала API о занятости для любого корректного значения, включая предзаполненный свой же ник. API отвечает available: true честно — переслать свой ник значит не занять ничего (комментарий у checkUsername в src/api.ts), — но человеку это показывали зелёным на имени, которое занято им самим. Добавлен признак unchanged (значение равно сохранённому у аккаунта) в условие эффекта: вопрос не задаётся, поле нейтральное, подсказка под ним — правило формата. Как только ник реально меняется, проверка работает как раньше. Чинится один раз для обоих экранов.

2) Слова под аватаром. Заменено в обоих словарях: Add your name / Добавьте имя вместо отчёта об отсутствии.

3) Красный выход. Кнопка выхода переведена с danger на secondary. Rust кит держит за необратимое (секция 2), а войти снова можно. Лист подтверждения оставлен как есть — он был принят в TASK-44 и композицию экрана не трогали.

Проверка: 123 теста и tsc зелёные уже после слияния с origin/main (пришли TASK-90 с переключателями темы и языка в профиле и TASK-72). Конфликт был один — докблок профиля, слит с сохранением обоих смыслов. Полный iOS-бандл собирается через Metro, все три правки в нём есть.

Живьём в симуляторе экран увидеть не удалось, и это стоит знать: в Expo Go проект не открывается без одного касания системного диалога Открыть в приложении Expo Go, а прав на управление экраном у агента нет; вдобавок вход по почте на стенде закрыт — /auth/email/start отвечает 503 mail not configured, README про строку magic link issued в логе устарел. Заведён тест src/profile-screen.test.ts (текстом по исходнику, как home-screen.test.ts) — он ловит обе молчаливые регрессии.

Замечено и не тронуто: кнопка Log out на самом листе подтверждения по-прежнему danger-solid, то есть те же слова в том же красном одним касанием ниже; чтобы убрать, нужно либо снять лист с выхода (композиция), либо дать ConfirmSheet ручку варианта (поверхность кита) — решение дизайнера. Приглашение Добавьте имя ведёт в никуда: задать имя в приложении нечем, оно приходит от провайдера входа, в api.ts нет putName. Свечение и активность кнопки Change username при неизменённом поле — это TASK-74, признак unchanged для неё уже лежит рядом.
