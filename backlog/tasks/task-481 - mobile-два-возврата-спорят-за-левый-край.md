## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Требует настоящего телефона: в node не видно, два это жеста или один. Проверяет chief как часть приёмки этапа m-34.

Читанием найдено и подтверждено: src/app/_layout.tsx:156 — screenOptions={{ headerShown: false }} без gestureEnabled, то есть системный возврат по краю на iOS остаётся включённым; gestureEnabled не встречается нигде в src/. Свой жест — useEdgeBack в том же _layout.tsx:96, на корневом виде.

Лечится gestureEnabled: false на стеке в этом же месте — отключает именно системный возврат по краю, остаётся один, наш.

Побочка, назвать честно: так отключится возврат по краю на всех экранах разом, а не только в просмотре. Человек просил «с левого края в центр возвращать назад» — то есть наш жест вместо системного, и на всех экранах тоже.

Это решение о том, чей это жест, а не о том, работает ли он. Если дойдёт до выбора — решение chief, а не кодера.
