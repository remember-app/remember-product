# Mock services

Локальные заглушки для разработки. Код приложений не знает, настоящий сервис перед ним или мок:
меняется только адрес.

- `mock-ai/` — заглушка модели для воркера монтажа.
- `mock-api/` — заглушка API для мобильного приложения.

Запуск:

- `make start-mock` — весь мок-стенд: мок-API, монтаж с мок-ИИ, мобилка на мок-API;
- `make api MOCK=1` — только мок-API (хост 7300);
- `make montage MOCK=1` — монтаж с мок-ИИ (хост 7801);
- `make mobile MOCK=1` — мобилка на мок-API.

Моки живут на портах с семёркой — 7300 и 7801, — поэтому поднимаются рядом с настоящими
сервисами на 3000 и 9000.
