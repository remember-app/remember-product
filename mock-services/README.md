# Mock AI

Локальная заглушка API модели для воркера монтажа. Отвечает на тот же протокол, что и Gemini,
поэтому код приложения не знает, настоящая модель перед ним или заглушка.

Запуск из корня репозитория:

```
make start-montage-mock
```

Поднимается сервис `mock-ai` и воркер монтажа с адресом
`http://mock-ai:8080/v1beta/interactions`. С хоста сервис доступен на `http://localhost:8080`.
Боевой режим — `make start-montage`, там адрес не меняется и запросы идут в настоящий Gemini.

Что отвечает:

- на запрос режиссёра — план монтажа по отчёту: все кадры поровну, переходы 0,25 секунды,
  первый трек;
- на анализ фото, видео, звука и музыки — короткие фиксированные описания и оценку 5.
