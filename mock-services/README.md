# Mock services

Локальные заглушки для разработки. Код приложений не знает, настоящий сервис перед ним или мок:
меняется только адрес.

- `mock-ai/` — заглушка модели для воркера монтажа.
- `mock-api/` — заглушка API для мобильного приложения.

Запуск:

- `make start-mock-ai` — только мок AI;
- `make start-mock-api` — только мок API;
- `make start-montage-mock` — мок AI и монтаж;
- `make start-mobile-mock` — мок API и мобилка на нём.
