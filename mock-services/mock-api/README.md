# Mock API

Локальная заглушка API для мобильного приложения. Отдаёт те же пути, что и настоящий API,
но из заготовок: проекты, галереи, песни, шаблоны, монтажи, ролики, вход.

Запуск отдельно: `make start-mock-api`.
Приложение с мок-API: `make start-mobile-mock` — поднимает сервис и запускает мобилку
с адресом `http://localhost:7300`.

Порты: реальный API — 3000, мок-API — 7300; так они могут работать одновременно.
Мок AI — 7801.

Медиа лежит в `media/`; адреса картинок и трека подставляются из адреса запроса, поэтому
работает и с симулятора, и с телефона в локальной сети.

Вход: на любой адрес запрашивается код `123456`; другой код не принимается. Код приглашения
в онбординге — `MOCK01`; другие коды не принимаются.
